# 四绿巽卦 · 辰巽巳三山

> 后天巽居东南，九星四绿；巽为风、为入，主的是「相互作用」——你往前走的时候，周围怎么看你、你怎么影响周围，所以一卦总纲落在「风评」二字。
> 三元龙分工：**辰为地元龙（实际含义＝能不能抢到）、巽为天元龙（根本内涵＝强不强、众口服不服）、巳为人元龙（人性影响＝正不正、落在谁身上）**。
> 一句话总纲：**辰看能不能抢，巽看强不强，巳看正不正**；三者齐了，才是「曾许人间第一流」。

## 卦体 · 四绿巽卦整体

> 巽为长女、为风、为入，四绿是其九星名。断整体先立一个前提：**巽卦的全部吉凶，都落在「关系」上，不落在行动力上**——它不管你做不做，只管周遭捧你还是攻你。

### 论断

巽＝一户人家与周遭的**相互作用**：行进过程当中对周围环境、人、事的影响力，以及周围反过来对你的影响。震卦讨论「你能不能往前走」，巽卦讨论「你往前走的时候，周围怎么看你、你怎么影响周围」，所以巽主风评、主悠悠众口。

- 卦体主：长女、长媳、风、入、绳直、工、白、长、高、进退、木果、近利
- 五行属**阴木**（与震之阳木对举）：主生发、主条达，也主柔韧
- 卦形**巽下断**——初爻为阴，根儿是虚的。所谓见砂，就是把这个根儿补齐；根虚则易被牵动
- 身体归**神免内**三系统：神经、免疫、内分泌。讲义列的人体对应还有头发、气管、胆经、肱股、呼吸器官、食道、肠道、左肩、淋巴系统、血管，但主记神免内即可
- 疾病统一逻辑是「**巽为入**」：胆疾、中风、伤风、感冒、受风、风湿、坐骨神经痛、神经痛、神经炎、寒痹症、抽筋、胯股病、支气管炎、哮喘、淋巴疾病、忧郁症——凡外部侵扰者、凡感染类疾病、凡邪风干扰，都归巽
- 整个巽卦坏掉：神经系统受破坏、免疫系统病入膏肓、内分泌系统完全紊乱；中枢神经出问题可见语言混乱，日常则是小风一吹感冒、一热中暑、吃点凉的拉肚子、一天没睡觉难受三天

一句话记住：**巽主「外来的东西进来」**——风、寒、湿、别人的话、别人的评价，都是进来的东西。

### 技法

**一、砂水是能量指标，不是物件。** 判断一样东西是砂是水，不看它「是什么东西」，只看它在当下这个位置「呈现什么性质」：能量活跃度高、密度低的是水；阻碍能量流动、让通过变难的是砂。门、窗、通道是水；高柜、大衣柜、书柜、大型家电、水晶玉石一类摆件是砂。

| 物件 | 判定 | 依据 |
|---|---|---|
| 冰箱（含双开门） | 砂 | 制冷时四周散热，周围能量被扰乱；里面凉不代表周围凉 |
| 空调内机（出冷风） | 偏水 | 出冷风、形成气流通道 |
| 空调外机 | 砂 | 强发热、强扰动 |
| 桶装饮水机 | 砂包水 | 以砂为主，带水性 |
| 现制直饮水机 | 砂 | 长期通电、耗电量大 |
| 老式波轮洗衣机 | 水包砂 | 运转时水汽外散，以水为主 |
| 新式滚筒洗衣机 | 砂 | 水汽不外散、机体发热 |
| 太阳能热水器 | 砂包水 | 一天 23 小时是砂，用那 1 小时显水性 |
| 超市开放式冷柜 | 水 | 开放、冷气外散、能量密度降低 |

- **砂包水／水包砂**：按「一整天」的时间占比判定——大部分时间呈砂性、偶尔显水性是砂包水；大部分时间呈水性、偶尔带砂性是水包砂。
- **体量门槛**：一杯水不算，十来杯才算；小盆花、多肉哪怕摆十几盆也不算；一米以上、比人高的绿植算砂；40 见方以上鱼缸算水，60 见方、不带盖、带过滤的空气缸是强水。空间越小，小物件越算数——两三平米的小办公间里，一个斗鱼缸、一盆绿植就可能起作用。
- **严格表述**：不说「这个东西属砂」，要说「盐灯在卧室内是否呈现砂性？鱼缸在客厅内是否呈现了水性？」——落点是它到底能不能达到影响能量指标这个层面。

**二、九宫格分能量。** 先把空间切成九宫，按八卦方位决定每个扇形该高该低：震、巽（正东、东南）能量密度高一点，东方主生发、宜起势；离（正南）、乾兑（西北、正西）、艮（东北）宜干净、清、能量低一点。该高的高、该低的低，能量才走得出漂亮的太极形。

**三、读经与布局的硬规矩。**

- **「会某出」＝水口**。经文里但凡见「会巽出」，同时告诉你两件事：巽方是水口（水消失的地方），巽方有山（高耸的山或一道拦水坝让水聚到这里再流走）。有水口、有山，才聚得住财；「长媳持家增财富」不是凭空断的。
- **水口倒左**：逆时针流水＋符合三神过水法（小神、中神、大神依次而上）→ 起码能留财存财；顺时针流一般有问题。住一楼、有小院想做小水池小水沟，一定做成逆时针。
- **环抱水与以水推山**：水从艮流到巽、环绕了东侧，既然没流到正北，说明坎卦必然有山（地势高）；正东震卦因水从这儿过，形成砂性。正北大山＋正东有砂→长子有钱。经文只写了水，山是隐含条件。
- **一卦纯清**：做对宫相催，一个局只用一个卦、同一元龙，千万别兼。两山交界的**空亡线**、跨两卦之间的**骑缝线**都不放砂、不放水；三点定位三处必须同元龙。一旦兼了，家中能量与人事关系必乱。
- **高级三点定位**：分界线是「家里已经没问题了」——砂水、格局、家具全部到位之后，才可以不考虑对宫增益，只用先后天关系去增益自己的诉求。巽（砂）→坤（砂，二黑山）→坎（砂）三处齐备，就是富贵双全之家。

**四、调运次序。** 相对于累积坎卦的能量和坤卦的顺滑，巽卦更早带来结果；最难解决的是震、巽，也最应该第一个考虑。

| 客户状态 | 该动哪个卦 | 依据 |
|---|---|---|
| 公司死气沉沉，有客户、有单子，就是不盈利，人人无精打采 | 震卦 | 行动力与士气问题 |
| 公司墨守成规、不愿进步、抱着吃老本、不想当行业翘楚 | 巽卦 | 自强与风评问题 |
| 个人生活无大问题，只是缺勇气、缺方向、易被否定打倒 | 震＋巽 | 校正思维、建立自我评价 |

一句话：**先看是「没力气」还是「没志气」——没力气调震，没志气调巽；坎坤管身体与财，震巽管一个人还要不要往前走。**

# 辰山 · 抢夺（能不能抢到）

> 方位 112.5°–127.5°｜五行 湿土（水库）｜地元龙＝实际含义
> **一句话记住：辰山看的是「你有没有那个能量去夺」——见砂是自己抢、搞垄断，见水是被别人抢。**

## 山性类象

| 项 | 内容 |
|---|---|
| 字义 | 辰，震也，物经震动而长；辰月是季春，木气最重 |
| 土性 | 湿土：辰、丑为湿土（生金不克水，像泥巴），戌、未为燥土（克金泄火，像岩浆） |
| 物性 | 辰为草泽、为水库；类象湿泥、池塘、沟渠、田园 |
| 人体 | 皮肤、肥肉（非肌肉）、肩胸背；女性右侧副乳／结节多应巽卦，左侧多应坤卦 |
| 性格 | 见砂：垄断、排他、把资源夺走；见水：不好意思拒绝、不自律 |
| 口诀 | **一记抢夺，二记湿土水库** |

**辰山的关键含义＝「抢夺」**。辰属巽卦地元龙，地元龙管的是这个卦最直接的实际含义，所以辰山就是垄断、排他、把资源夺走——它不问「名」从哪儿来，靠抢才换这名。

理解的关键在卦形：**巽卦是「巽下断」，根儿是虚的**。由此推出两条：

- 自身能量过强——你去抢夺别人，实力够强、能量内核足，可以去搞垄断、铺开能量、发散影响力；
- 自身能量不足——你被抢，实力不够，有不抢你就有被别人攻击的点。

「苍蝇不叮无缝的蛋」，抢夺的背面看的是这个人的自身能量内核。所以辰山的落点终究是**打铁还需自身硬**：本身是臭鸡蛋，就别怪苍蝇来盯；行得正、走得直，别人的攻击只会成为你成功的资料。

三元龙里辰问的是「**能不能**」——你有没有那个能量。辰（地元龙）管最直接的实际含义，巽（天元龙）管集中表达与底层逻辑，巳（人元龙）管与人联系最紧密的使用方式。

**两层要分开看**。辰山见水的人，是**被抢**的那一方：好东西别人要就给，知识别人求就教，时间金钱精力全被拿走——只因不好意思拒绝，不是没能力。第二层更根本：**不自律、自作自受**，痔疮、溺水、皮肤瘙痒都归到神免内三系统管不好自己。

**缺＝见水**。缺角能量低、活跃度不高、过于通畅，从基础上论可以直接论为见水；巽位缺角不必真见水，效果等同见水——能量是「漏」不是「无」，周遭态度从追捧翻转为对抗。

**真修行者能反超**。辰山见水的弊端是容易不自信、不自律、熬夜、饮食不规律、摆烂；若能拨乱反正——每天保持自信、坚持自律健身打坐、完善作息、让别人一见到你就如沐春风——这时辰山见水爆发的能量，很可能比辰山见砂还要强大。讲师据此自况：不去补自家的辰山，宁可让它缺着，把不良反应内化，再外放成一股力量。学风水就是修行：你与环境本为一体，不去改变环境、反而改变自己，它爆发的能量比直接调环境强大得多。

## 技法与布局

**漂转与深挖**（全卦通用，辰山第一次给严格定义）：

- **漂转**＝找该卦的**先天位**（「老家」），是根、原因、缘由；
- **深挖**＝找该位置的**先天卦**（跟在后面的那个），是形容、体现。

巽卦标出来：先天位在西南（坤），先天卦是兑。深挖巽挖出兑，漂转巽指向西南坤。凡涉及「先天位」是病根缘由，凡涉及「挖」是形容体现——辰庚配水走深挖，未水加配走漂转。

**一卦纯清**：任何三点定位都保证同元龙。辰的对宫戌（乾第一山）、辰的先天位未（坤第一山），三者同属地元龙；换成申（人元龙）元龙就不统一，问题便落到「人」、落到女主人身上。推论：**四正位**（坎震离兑，子午卯酉）五行统一、得其清；**四隅位**（乾坤艮巽）五行混杂、能量更凶但「不够清」。修炼择时选四正，布局三点定位也要同元龙——「要砸一起砸，要存一起存，要好到极致，要坏坏到底」。

**论断模板**：辰山见水直接断「这家人不自律、自控弱、hold 不住、意志弱」；进阶断长女婚恋被抢、胃肠炎、乳房结节、痔疮、溺水、皮肤瘙痒。孩子老被欺负，把他房间的辰、戌、丑、未四山按需调起来，一放就没人敢抢，但不能久放。

**多白眼与翻白眼**：为什么巽卦对应「多白眼」？因为太注意别人的想法。人的瞳仁缩小时一般是惊恐、不安、没有安全感的时候，一个人没有安全感，眼白就会非常大；黑眼仁小、下眼睑都是眼白，就是翻白眼，核心特征是**缺乏安全感**。常被说「不能交」的原因，是缺少安全感的人通常会通过伤害别人来满足自己；好的一面是有危机意识、对风险的把控非常强。讲义特意补了一句：翻白眼的好人很多，只是对不熟的人、初次见面的人保持极强警惕——不要贴标签。

**巽卦的本质：相互作用**。可以想象为一个人在行进过程当中，对周围环境能量、人、事的影响力——所以它跟头发一样多、跟神经一样密集、跟内分泌系统一样牵一发而动全身。

| 维度 | 震卦 | 巽卦 |
|---|---|---|
| 讲什么 | 向前的增进能力、爆发力、突破力 | 行进过程当中对周围的影响，以及周围对你的影响 |
| 关键词 | 主动、出击、突破 | 相互作用、关系、风评 |
| 失效时 | 行动力不足或滥用 | 要么慕强被牵着走，要么自强引领风向 |

| 巽峰出状元／巽卦即文昌卦 | 不能一概 | 太过宽泛；真正催文昌要看具体的山、水、形，还要看对宫有没有能量来照 |
| 巽峰主文官多应，不主武 | 不对 | 文武都会出；巽为长女、为绳直、为工，既可出文，也可出武 |

**「慕强」的六种外延**：它不只作用于感情，是一套完整的行为模式。

|---|---|---|

两个极准的细节：一是**安全感依赖**——同事特别厉害，他坐你跟前你就文思如泉涌，他今天请假你就什么活都干不了，哪怕他只是坐在旁边提供情绪价值；二是**自我加滤镜**——这个世间本没有佛，是你的注释为他镀上了金身，在心里给别人构建强大形象，认为自己不行、别人行。所以巽山见水是「风评」最集中的表达：要么慕强、被牵着鼻子走，要么盲从舆论、成为乌合之众。

**磁铁与铁屑**：巽山见砂，你是一块磁铁，周围都是小铁屑，你的磁场怎么定，他们就跟着你怎么走；巽山见水，你是一块破石头，或者你自己就是铁屑，别人怎么吸你怎么去。

**女当家，主的是风评不是财富**。巽为长女卦，巽砂女当家时家中女主人能量非常强大，但主的是家中的风评、这个家的气质，不是家中的财富。理解这一点，就能解释震巽两卦同时见水为什么夫妻不和：震卦见水是行动力乱、乱跑、「我不好好干活」；巽卦见水是慕强、看别人好、见你又不爽、自己还不干；两个加起来，整天瞅你不顺眼，肯定要吵架。反过来巽山见砂，不管他家男人争不争气，女人一定是争气的——人争一口气，我就不能比别人差，一定要让别人看得起我。

| 定位 | 名牌效应、垄断、有核心竞争力 | 吃老客户、靠人情 |

# 巳山 · 拔尖（正不正）

> 方位 142.5°–157.5°｜五行 巳火／大驿土｜房份 二房（中子）｜人元龙＝落在谁身上
> **一句话记住：巳山看的是「出的这个头正不正」——见砂是拔得头筹、人间第一流，见水是另辟蹊径、在小众赛道上拔尖。**

## 山性类象

| 项 | 内容 |
|---|---|
| 字义 | 巳，起、已：万物至此已毕尽而起 |
| 时令 | 孟夏，农历四月，巳火最旺 |
| 土属 | 大驿土：人烟密集、道路通达；巳的下一位是午马，马上到达鼎盛，人马往来、车水马龙 |
| 地支 | 巳为蛇（民间论断多从此附会） |
| 场所 | 烟火、汇聚人烟之所、市集、小城镇、道路、寺观楼台 |
| 人体 | 咽喉、齿、肛门、眼目、心脏系统 |
| 性格 | 见砂：处处拔尖、人中龙凤；见水：猎奇、换赛道、闲不住 |
| 口诀 | **一记两端论，二记拔头筹** |

**巳＝起：万物至此毕尽而起**。就像天干走到戊己庚辛壬癸那个阶段，大家都上来了、都到台上了；模特走秀，在 T 台上走来走去，眼花缭乱，真漂亮——这就是「物」的阶段。这个类比解释了巳山的一个特征：出彩、耀眼、夺目，但同时「分不清是谁」，名气很大，具体成就却容易被混淆。

**为什么这类人闲不住**：巳为大驿，人烟密集、道路通达；八字里临到大驿土的人，大多爱奔波、爱劳碌、闲不下来。象不是背下来的名词，是能推出行为特征的模型。

**身体：通道的两端**。巳火对应咽喉、齿、肛门、眼目、心脏系统，注意这几个部位的共性——

| 部位 | 属性 | 说明 |
|---|---|---|
| 咽喉 | 通道入口 | 食道的开端 |
| 齿 | 通道入口 | 口腔门户 |
| 肛门 | 通道出口 | 消化道的末端 |
| 眼目 | 感官窗口 | 与心火相应 |
| 心脏系统 | 火之本体 | 巳属火，故主心 |

巳所引发的问题，大多出在**人体通道的终端**——不在中间，在两端：食道要么是咽喉、要么是幽门；肠道要么是十二指肠、要么是结肠、盲肠、肛门；免疫系统是甲状腺（前端）、阑尾（末端）。这个「两端论」是后面理解巳丙相催病理链的基础。

**巳字应事三条**：底本列的三条民间断诀——「穴地巳水来、子水出，主蛇鼠同居于穴中」「巳方有路向宅、巳方有水入宅前，主蛇入宅之应」「收巳气之宅主出长颈人」——讲师逐条判为附会：拿地支对应动物去断实际动物、拿某一山去定长相，都属江湖派的愚昧解释。这一段是提醒：民间断诀要分层看，象学部分可用，动物附会部分要丢掉。

**巳在巽卦三山中的位置**：最后一山，也是最特殊的一山。辰管「能不能抢到」，巽管「强不强、风评如何」，巳管的是「**正不正**」——能否拔得头筹，以及方向是否对。巳山最能「拔尖」：正道上能拔尖，左道上也能拔尖；关键不是「能不能出头」，而是「出的这个头，走的是通天大道还是旁门左道」。是上穷碧落下黄泉之姿，还是蝇营狗苟之辈；是引领风尚的先辈，还是人人喊打的角色；是要成为人中龙凤，还是要遗臭万年。

三元龙里巳问的是「**落在谁身上**」——这事具体发生在哪个人、哪个部位。辰问「能不能」（有没有能量），巽问「怎么被看待」（别人服不服你），巳问「落在谁身上」。

> 巳水女人配秃郎　偷情老夫入香房
> 丈夫若是有头发　无情夫妻不久长
> 水形如若七八杈　女人性乱必为娼
> 巳未亥来都显水　抛弃子女爷抚养
> 巳丙兼水甲亢病　男痔疮女咽喉
> 巳丙水来壬亥砂　长房中年尿毒症

讲义对经文二判为有误，故不逐句展开；从文句看，经文一作「夫若无头发，假夫假久长」，经文二作「丈夫若是有头发，无情夫妻不久长」，一正一反，都在说这层关系不牢。经文三前三句同义，从第四句起才是重点。

### 逐句转译

| 句 | 字面 | 实质 |
|---|---|---|
| 巳水配秃郎 | 巳方见水，配了个秃头男人 | 配偶或交往对象「非主流」：外形、职业、身份有特殊标记 |
| 僧人入香房 | 和尚进了女子的卧房 | 对象属「特殊职业」——宗教、玄学、演艺一类 |
| 夫若无头发 | 丈夫若是秃头 | 巳山本身就主脱发，见水尤甚 |
| 假夫假久长 | 这种夫妻关系不长久 | 关系建立在猎奇而非日常之上，难持续 |
| 形若七八桠 | 水形像树杈分叉七八道 | 形煞：水形破碎、分叉、不聚 |
| 秦楼楚馆娘 | 家中女子流落风月场所 | 异乡流入风月场所（农村多见，城市少见） |
| 巳未亥来都显水 | 三处同时见水 | 抛弃子女爷抚养：家里的老人特别着调，年轻人都不着调，孩子只能由老人带 |
| 巳丙兼水甲亢病 | 巳丙之间见水 | 男痔疮女咽喉，详见病理链 |
| 巳丙水来壬亥砂 | 水在巳丙、砂在壬亥 | 长房中年尿毒症 |

**核心不是「好色」，是「猎奇」**：执念于某一类特殊对象。讲义用高阳公主作例——她一生偏爱与僧、道往来，根源是早年与一位出家人相恋、遭世人诟病，从此对这类人有了执念；由此接回一条论断：所有求而不得的执念，其实都是反复在同一种人身上寻找。对象越特殊，说明这股能量越没处安放。

**民国语境**：什么样的家庭会出「和尚进闺房」这种事？答案不是下九流，而是有地位、生活比较正常的家庭——基本需求已经满足，接下来求的是刺激与新鲜感，一般行业入不了她的心。所以巳山见水不是「穷得没办法」，而是「条件够了、阈值高了」。

**现代转译：特殊职业与制服控**。「秃郎」「僧人」翻译到今天，就是「有特殊职业或特殊特征的人」：偏爱玩摇滚、玩说唱的；偏爱某种手艺行业的；制服控——对特定职业装束有偏好；偏爱玩刺激的。共同点是这些人身上都有一个「标记」，跟主流审美不一样——我喜欢的人跟你们不一样，小众爱好。反过来，如果一个人喜欢的是大众偶像、大众情人，那就不算巳山见水。

**夫若无头发：巳山见水必脱发**。经文里这句既是断事，也是生理提示：脱发是最直接、最轻的应验。讲师还补了一层：如果丈夫本来就秃，家里反而不容易出前面那些事——因为「秃」这个象已经应掉了。「掉几根头发换来一家人不作妖，难道不好吗？」象总要找一个出口，出口轻了是好事。巳山见水是整个巽卦三山中最容易脱发、头发出问题最严重的一山。

**城市版：不是色情，是公关**。同样一个巳山见水，在城市里通常表现为公关能力极强——在公司里担任公关工作，或公关能力特别突出，「别的不行，喝酒第一名」。跟六煞的逻辑类似：正常能力竞争不过，就走人脉路线，攀附厉害的人然后超过你。这类人不一定是社牛，可能平时挺社恐、是个 I 人；但一到合适的场合，一定是最突出、最会来事的。巳山见水的现代形态是**换赛道竞争**：正道上排不了第一，就在人脉、关系、场面上排第一。

**三个附加特征**：经营上容易出现恶性竞争（一旦有人挑起，要么想跟他拼，要么自己发起）；孩子考试爱作弊（「这场考试他不作弊，心里就难受」，本质还是走捷径的惯性）；脱发反而是好事（象应在了头发上，就不容易折腾到家庭关系上）。

**三层后果**（最值得背下来的一张表）：

| 层级 | 表现 | 说明 |
|---|---|---|
| 最轻 | 脱发、头发出问题 | 象应在了身上，家庭反而安稳 |
| 中层 | 小众爱好、被人牵着鼻子走 | 开始偏离主流评价体系；容易被宗教、玄学、江湖人士带走 |
| 最重 | 另类、与众不同，发展到不择手段的公关 | 正道拔不了尖，就在别的赛道拔尖，接受度与阈值都极高 |

一句话记住：**巳山见水干啥啥不行，搞另类第一名、搞小众爱好第一名、不择手段第一名、脱发第一名**。

**巳丙相催病理链**（本课最实用的一条）：

| 环节 | 内容 | 依据 |
|---|---|---|
| 起点 | 巳丙之间见水，或巳与丙同时见水 | 两山相邻，能量叠加 |
| 传导 | 巳把神经、免疫、内分泌三系统上的不良之处交给丙火 | 丙属离卦，离主火、主炎 |
| 发作 | 发炎——甲亢、甲状腺病 | 火性上炎，甲状腺在颈前 |
| 连带 | 男性痔疮、女性咽喉 | 人体前端与末端同时受火 |
| 免疫 | 甲状腺（前端）、阑尾（末端） | 与两端论一致 |

读法是：**巳是「因」，丙是「出口」**——巳的问题不会停在巳，会顺着丙火发出来，所以看到甲状腺、甲亢，要回头看巳丙这一线。「巳丙水来壬亥砂，长房中年尿毒症」是这条线最重的一格：壬亥之间见砂本身就有问题，会让家中男性出现头疼、痛风一类阻塞病，这类「堵」再加巳丙的水，堵得太厉害、垃圾排不出去，就是尿毒症。这是少见的把「病名＋房分＋年龄段」三样都点明的断语，实战价值高，也最需要谨慎表述。

**巳山见水与玄学受骗**：讲师给出一段心理机制——现实里赚不了你那么多钱、没你那么有名，那我靠什么赢你？靠「心善、能积累福田」。检验方法是：家里东南方向是卫生间或放了洗衣机的，回想一下被多少「大师」「道长」许诺过福报、花过多少钱。落点是：**巳山见水的人，判断力的缺口在「自我价值」这一块**，最容易被许诺「福报」「捷径」的人拿走钱。

讲义对经文二只一句「没什么好说的」——与前段同义，无新增技术点；经文三后三句才是重点。

### 逐句转译

| 句 | 字面 | 实质 |
|---|---|---|
| 巳砂文书发 | 巳方见砂，主文书、文采 | 与文化、文字、公务相关的能力 |
| 中子称美豪 | 二房出类拔萃 | 底本注二房；讲师的经验是不必拘泥房分，一家人整体都不差 |
| 形如赤蛇绕 | 山形红色、盘旋环绕 | 形吉：有势而不散 |
| 官清似尔曹 | 为官清正 | 清官，不贪 |
| 形若葫芦样 | 山形像葫芦（上小下大） | 主宗教缘、出家为方丈 |
| 有子为方丈 | 二房出家且为有为之人 | 为方丈或高僧 |
| 形若尖峰起 | 山形高耸有尖 | 主财与名同时到 |
| 财高名声大 | 财厚、名声大 | 因财得名、因利得名 |
| 巳位配上丙位砂 | 巳位之优秀被丙放大 | 清高气昂上进难，见下 |
| 若再配上乾亥砂 | 对宫相催 | 女争男斗子不孝、姐妹媳妇也不合、喜怒哀乐暗言斗 |

**「当第一」：引领风向的代价与条件**。讲师把巳山见砂的意义提炼成一句大白话：你哪怕去寺院里，你都是主持、都是一把手；当官一把手，念书一把手，到哪都是老大、到哪都显眼、到哪都能引领整个能量场。连问四句把这条路的诱惑讲透：你想引导方向吗？你想得到这种拥护吗？你想众星拱月吗？你想成为如英雄般夺目灿烂的人物吗？答案是残酷的——**没人记得第二，只记得第一**；只有当了老大，才有可能去引领整个舆论、管住别人的嘴。乔峰哪怕当乞丐，也是丐帮帮主。这不是鼓励蛮干，而是说明一个结构性问题：**位置本身就是一种能量**。

**三山一句话串起来**：辰山见砂，我能搞垄断；巽山见砂，我能自强不息；巳山见砂，我能拔得头筹。巽卦是很好的一个卦——用得好，能让一个人的经历、行动力、能力得到完全展现，是达成阶级跃迁的卦，到哪儿都是人中龙凤、都是天之骄子，就不会成为众矢之的；反过来，巳山见水就是众矢之的，都戳你脊梁骨。标题「曾许人间第一流」，贴切的正是巳山。

**清高气昂上进难**：巳位本身代表「你优秀、你厉害、你聪明」，配上丙位砂之后，这层优秀被放大，但眼界同时被收窄——看不上别人，容易得罪人。例子很生活化：我是我们班语文第一名，那我就跟数学第一名玩；结果毕业以后，名次靠后的同学当老板了，去人家那儿应聘，人家还不要你。根子在离卦：离主开明、主前景、主眼光；光自己优秀、挺聪明，没有眼光、不考虑自己的前景，就成了清高气昂上进难。

**女争男斗，乱成一锅粥**：巳丙间砂再配乾亥砂，机理是阴盛阳衰——该男人好的卦不好，该女人好的卦是好的，但女人又觉得自己了不起，两头都不服。「暗言斗」三字很传神：不是明着吵，是背地里说、互相较劲；这类家庭表面和气，内部消耗极大。

**巳山见砂的常见病**：巳丙间砂最容易出现痔疮和甲状腺；此外几乎无例外的一条是——巳山只要有问题，不管见砂见水，这个人一定喉咙容易上火、嗓子比一般人敏感，容易支气管炎、慢性咽炎，别人感冒先打喷嚏、咳嗽、发烧，他感冒前先嗓子疼。原因还是两端论：巳主通道的两端，喉咙是最前端，所以最敏感。

**一句话总结**：巳山砂若尖峰起，定是人间第一流。

**一卦纯清：做局不许兼**。做对宫相催，记一句话：一个局只用一个卦、同一元龙，千万别兼，一旦兼了定然造成家中能量与人事关系的混乱。巳丙兼了砂、对宫兼了水又兼砂，都不行。玄空里把这叫**空亡线**与**骑缝线**——每个山的交界处都不允许放东西。

|---|---|---|
| 空亡线 | 两山交界、气不纯的界线 | 交界处不放砂、不放水 |
| 骑缝线 | 跨在两卦／两山之间 | 同上，等于无卦可依 |

| 兼卦 | 同时取两个山的气 | 除非确有师传特例，否则不做 |

## 技法与布局

### 三点定位与先后天

- 普通三点定位：考虑对宫增益；高级三点定位：格局全清之后，只用先后天关系增益诉求，不考虑漂、挖。分界线是「家里已经没问题了」。
- 巽（砂）→坤（砂，二黑山）→坎（砂），三处齐备，就是「富贵双全之家」。
- 三点定位查元龙是否统一——一卦纯清，绝不兼卦。

### 九宫与水流

- 小院水池／水沟做成逆时针（水口倒左），并符合三神过水法——起码能留财。
- 室内布局先分九宫：震巽宜起势、离乾兑艮宜清，再谈具体摆件。
- 环抱水不代表没有凶事：不管环抱砂还是环抱水，该吉吉、该凶凶；艮震之间有水主家族矛盾，震巽之间有水主家庭内部矛盾，矛盾是有的，但不妨碍这家人有钱、能量层级高。

### 现场操作

| 检查项 | 要点 |
|---|---|
| 巳方见水：查脱发与喉咙 | 最轻应验在头发，别忽略 |
| 巳丙一线：查甲状腺、甲亢 | 男看痔疮、女看咽喉 |
| 巳丙水＋壬亥砂 | 重点看长房、中年男性 |
| 身体问题分层查 | 症状→辰，开关→巽，零件→巳 |
| 判断客户是「没力气」还是「没志气」 | 没力气调震，没志气调巽 |

**辰巽巳三山见水的一天 vs 见砂的一天**（把整个巽卦讲活的两段白描）：

> 见水：现实里取得不了成就，上班被抢夺、被 PUA、被嘲笑；回了家又羡慕老板、羡慕一个一个成功人士，当一下网络喷子；到了晚上，躁动的心勾引着欲望，在见不得人的事情上找存在感。辰巽巳三山见水，就是生活里的失意使你在处处都无法触动，然后在其他一些事情上找存在感。
>
> 见砂：工作里处处能够垄断资源，所有乙方都要听他的话；同时能在大众当中引导舆论方向朝我而来，让大家觉得我很优秀、跟着我走，因为我能引领整个行业的走向。晚上回到家复盘白天的功绩，依然有人称我是业内翘楚、商界精英。

同一天，两套剧本：一套是「在外面输、在暗处赢」，一套是「在外面赢、回家还在赢」。差别不在努力程度，在赛道正不正。为什么说巽卦不好容易「淫乱」？因为**在别的地方找不到存在感**——不是欲望强，是价值感缺。所以巽卦见砂的解法不是「压抑」，而是「给他一条能在正道上赢的路」。

## 本卦小结

巽卦三山，讲的是同一股「关系」的三段：**辰给能量、巽给风评、巳给方向**。三山都怕水，因为巽为入——水一泡，根就虚了，人就被牵着走；三山都喜砂，因为见砂就是把巽下断的那个根儿补齐。

| 山 | 见水 | 见砂 | 落在谁身上 |
|---|---|---|---|
| 辰 | 被抢、不自律、痔疮溺水、缺角等同见水 | 能垄断、发富但名臭、做出头鸟遭反噬 | 自身能量内核、长女婚恋、皮肤肩胸背 |
| 巽 | 慕强、被引领、淫乱、耳根子软、激素失衡 | 自强、女当家、名牌效应、村邻赞许 | 长女长媳、悠悠众口、核心激素开关 |
| 巳 | 另辟蹊径、猎奇、脱发、公关、玄学受骗 | 拔得头筹、文书发、财高名声大、人间第一流 | 二房／中子、甲状腺与肠道末端、方向正不正 |

**三山身体信号的三层**：辰告诉你「哪里不舒服」（症状层），巽告诉你「为什么会这样」（开关层），巳告诉你「具体坏在哪个零件」（零件层）。脱发查辰山只是治标，查巽山才找到激素这个开关，查巳山才知道是甲状腺还是肠道末端。

**断巽卦的次序建议**：

1. 先问一句：**这个地方该不该要巽山强**——场所用途不同，同一个卦位的吉凶判断可以完全相反
2. 一看**辰**（能不能抢到）——自身能量够不够，是被抢还是抢人
3. 二看**巽**（强不强、众口服不服）——慕强被引领，还是自强引领人
4. 三看**巳**（正不正）——正道拔头筹，还是小众赛道另辟蹊径
5. 三山都看**对宫乾**：能量好则增益后劲，不好则只加一个不好的形容（凶乾砂主男弱）
6. 三山都看**坤方先后天**：巽砂配坤砂才是个个夸，巽水配坤水则贤妻病亡——单山不断事
7. 布局先看**一卦纯清**：三点定位三处同元龙，空亡线、骑缝线不放砂水
8. 调理次序**震巽优先**：没力气调震，没志气调巽；坎坤问题放在后面

> 巽卦三课的总纲：**辰看你能不能抢，巽看你强不强，巳看你正不正**。三者齐了，才是「须知少年凌云志，曾许人间第一流」。整卦最该记住的一句是——它不管你做不做，只管周遭捧你还是攻你；**打铁还需自身硬**，自身能量足，攻击反成你的资料。
