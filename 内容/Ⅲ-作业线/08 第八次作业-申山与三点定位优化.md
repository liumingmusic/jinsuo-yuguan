## 我的回答 · 原文

一、第一题｜申山的核心理解

一句话核心：申山主打链接传递／链接沟通，不论见砂见水都有反应，差别只在链接的层次与程度，所以能用链接传递解释申山全部见水、见砂现象。

为什么是"链接"：申为伸展之意，位坤地西南、农历七月，是顽钝耐磨之阳金，地势广大无疆；申能像无线信号一样链接此区域内的一切人和事物，贯穿一维到 N+1 维的信息与灵性能量，既能帮你链接，也能帮你运营，因此西南有水的道观寺院一般比较灵验。其类象为仙堂、祠堂、大陆（条条大路通罗马）、金属矿石，人体对应大肠、经络、肺、骨骼、呼吸系统及消化系统与气血。也因申金耐磨，从经文得到的信息技能几乎受用终生，但一旦受申金伤害，影响同样深远持久、不可磨灭。

链接错（见水）：剑走偏锋：接触、认知世界的方式另类，产生歪曲不寻常的世界观；看到的是世间之苦与险恶，"知苦而不接受苦、不去历苦"，于是早恋怪癖、非主流、撒谎骂人，精神压力大乃至抑郁症、摆烂怨天尤人；病主要不在腹部，而在心理层面、和顺之意上。对宫相催把矛盾转移到兑卦，还会出现负能量外倾、心肠毒辣恶相言、女孩子晚婚。

链接对（见砂）：正确感知世间万物：理解世间之爱，成为蕙质兰心、内心干净纯洁之人，相由心生气质的女儿美（根源是脾胃好、气血好），知书达理、艺术细胞与第六感强、修行顺畅；申山见水导致的精神问题，申山见砂能很好地化解。隐患是"申砂兼庚位"——兼到兑卦后对宫相催，易出受气包、泼妇、官司口舌，或手术车祸。

二、第二题｜坤卦的核心理解

一句话核心：坤卦整体主打「家运」，特别强调"神助之韵"，见砂家运如有神助、大利可图，见水则家运受阴性因素干扰、无利可图。

见砂：家运通玄、祖宗蒙阴：整个坤卦如城墙一样全是砂，家运旺盛、财源茂盛，是祖宗庇佑、祖宗蒙阴、功德，家运好到"如有神助"；艮水一照则福寿双全、子孙旺盛，名利双收、远近闻名，局大清正还有贤内助。讲师对"坤卦催官"存疑，认为这里形容的其实是廉洁清明、对乡里有帮助的地主乡绅一类人物，而非真能催官。

见水：阴性因素干扰：坤卦见水最关键的就是阴性因素的干扰，家运"老起不来"。灵性能量过强、信息量太大而 hold 不住，容易愚昧妄信、巫觋出马、附体失眠多梦；流到兑卦后嘴碎乱说，重者韦尼克失语症，人远离你、无利可图。坎之先天为坤，先后天翻卦下母亲受影响；巽（长女长媳）与坤（女主）并见水，则女人身体或心理容易出问题。

但见水不一定不好：若形成环抱水势、格局高，家里人聪明、第六感强，甚至有遥视、天眼等常人没有的能力。坎坤皆见水而仍子女双全、父母安康，说明家中有潜心修行之人，把阴性能量作用为灵性能量、转化为修行之功，是更了不起的功德；先修人道，再修仙道。

对照要点：全见砂是祖宗蒙阴、功德；全见水的关键只在阴性因素干扰，除非以正修转化。

三、第三题｜三点定位法的优化公式（完整）

总公式：三点定位法＝用神卦 ＋ 用神的先天位 ＋ 诉求卦，优化后写作 用神卦（老二→坎）＋（兑）用神的先天位 ＋ 先后天关系 ＋ 诉求卦（家运好→坤），三点能量核心集中到用神卦。三点定位法代表的就是诉求，例如"我就想让家中老二好，而且我想老二的家运好"。

## 展开

### 一、申山：同一条通道，两个出口

正文把申水断在心理层面而不在腹部，这一条最反直觉。机制是通道过强、没有过滤：别人看见世间之爱，他看见世间之苦；理解不了苦，就被苦带走。所以"出神卜"与"出抑郁"是同一个开关的两个位置，差别只在这个场承不承得住。

申山的「我的经文」已收录，见 [Ⅴ-02 申山](Ⅴ-02-二黑坤卦未坤申.html#jw-坤-3-申山)；「老师经文」留 〔待补〕。底本三版见[申山](Ⅱ-02-02坤卦未坤申.html#申山-链接-探索与艺术)一节。这里不拿别处的句子顶。

核心理解压成两句：**申砂不是"变漂亮"，是心美而相生**——圆面长腰的底子是脾胃气血，不是五官；**申水不是"身体病"，是世界观的偏移**——先偏看法，后偏身体。这一层抓住了，申山的砂水就不会跟坤、未混。

### 二、坤卦整体：先定场，再定山

卦体不是三山的平均数，是三山共同撑起来的场。断卦次序必须先整体后单山：整体定格局，单山定落点。坤卦这一课有老师逐字版自译，可以直接引，不必自己动笔：

> 坤卦见水弱作祟，愚昧妄想变仙。
> 坎卦坤卦都见水，老母势必体难安。
> 家运兴旺子嗣全，必有僧尼潜心修。
> 坤砂坎砂兑卦水，老二兴旺运势强。

四句里藏着整体的两条规矩：一是**坤卦见水先断阴性因素**，这一层不属于任何单山，只在整卦上成立；二是**整体好时，坏的那一条会被"修"掉**——坤坎皆水而家运反好，是因为家里有位正修之人。所以整卦不能只数砂水，还要看这个场有没有"承住"的能力。

### 三、三点定位的优化公式

第一代写成式子是这样：

```
P₀ = U + O(U) + A(U)
```

U＝用神卦，O(U)＝用神对宫，A(U)＝用神先天位。三点全在描述用神自己——它是谁、它的对面、它的根。缺的那一层是"求什么"。

优化后：

```
P = U + A(U) + D
约束：D ∈ { 对宫(U)，先天位(U)，与 U 互为先后天的卦 }
```

代入讲义原例（催老二家运）：

```
U  = 坎（老二）
A(U)= 兑（坎之先天位）—— 先天好，好能量才会优先给用神
D  = 坤（老二的家运）；坤之先天位在坎，与坎互为先后天，合规
∴ 取坎 ＋ 兑 ＋ 坤
```

比第一代多出来的就是 D 这一项。D 一进来，第三点从"补用神"变成"定目标"，三点才有方向。约束条件是这条公式的命门：**诉求卦必须与用神有先后天或对宫关系，否则三点会散**——三个点各自发力，方向不一致，做完了等于没做。反例：把 D 取成巽（想催流量），巽与坎既非对宫也非先后天，局就散了。
