# 二黑坤卦 · 未坤申

## 卦论断（一卦之体）
- 二黑坤：母亲、家运、产能、利润
- 蕴养、消化系统、子宫、脂肪、胸乳
- 灵性能量沟通、阴性能量怪事、掌控欲
- 粉丝与流量
- 身体层：腹、肠胃、消化道、湿气、慢性病
- 一句话：坤看的是「这个家养不养得住人」
- 坤是财卦，但管利润，不管财库
- 财库在坎（子）、利润在坤、人头在艮

## 卦见水
- 总断：灵性能量过强、阴性因素干扰、家运起不来
- 二黑水当先，巫婆小姑仙 → 愚昧、什么都信
- 流神通丙午 → 讲师改断「长寿乐绵绵」，非短寿
- 水龙入兑位 → 阴邪、爱说迷信话，重则韦尼克失语
- 坤水＋坎水 → 老母体不安；平安者家中有正修之人
- 坤水＋巽水 → 女性皆不好：离婚、欲望大、身体差
- 离水环抱到兑 → 家人聪明、灵性高、天眼遥视
- 坤水＋子水 → 妇女湿气重
- 一句话：坤水不是「破财」，是「阴气重、家不暖」

## 卦见砂
- 二黑砂完全、金城一照眠 → 祖宗蒙阴、家运通玄
- 上中丁财盛 → 上元中元尤验
- 如得艮水照 → 福寿双全、有大利
- 局大官清正 → 出清正之人、贤内助（催官一层落成乡绅）
- 地泽天全砂 → 三房富贵、大房衰；大房富贵则父子缺
- 坤离满砂 → 三房旺、上中房辛劳
- 坤坎砂＋兑水 → 荣华富贵在二房
- 一句话：坤砂要「满」、要「叠」，满则如城

## 卦应期
- 上元、中元运最盛
- 坤水应女主人：名声、健康、运程三者应一
- 逢二黑、五黄之年尤验

## 卦兼与邻卦
- 坤的先天位在坎（正北）→ 坤水＋子水最深
- 对宫艮（东北）→ 艮水照则子孙旺，艮砂照则女强男弱
- 邻卦离（南）→ 坤离皆水主灵性、皆砂主辛劳
- 邻卦兑（西）→ 坤兑皆水主淫、药罐、失语
- 邻卦巽（东南）→ 巽坤并见水主克妻
- 兼卦三条件：跨卦＋一喜一恶＋相邻

## 一卦三山总纲
- 中间山主健康，两侧山主人事
- 坤居中 → 家运与妇科；未申 → 利润与链接
- 三山共一个「养」字：未谋利、坤养家、申通外
- 坤为母、为期，应全体女性，不论房份
- 未砂讲义作「大房中房」，未水作「三房」，口径不一

## 未山 · 利润（以利为先）
- 身体层
  - 胃、脾、肌肉、体脂、消化系统
  - 未山好 → 体脂低、有健身天赋
  - 未山见水 → 体脂高、发胖
- 见水
  - 未水出盗贼，事犯产收没
  - 形若斜飞去 → 战场寻尸骨（今读伤亡，不作生死断）
  - 军警官商有伤亡 → 这条路上的人都可能折进去
  - 现代版：土方、放贷、擦边、二级分销、虚拟币、股票
  - 未水＋丁水 → 胃疾吐血、经难调
  - 未水＋丁砂 → 串病：胃子宫 ＋ 心眼
  - 未水＋丑癸砂 → 同床异梦、分居
  - 断法语：问副业，不问盗贼
- 见砂
  - 未砂能发财，行为不正来
  - 军贼与土匪，名臭通六街
  - 形若眠夕秀 → 形好可走正路，置田庄
  - 丑水照当坏 → 在钱里迷失
  - 未砂＋丁字水 → 显财富、女能人
  - 未砂＋丑砂 → 自己赚、儿子败
- 兼与叠加
  - 临卦加强：未弱 → 丁见水（丁低则未高）
  - 反向：丁砂＋未水 → 阴阳颠倒
  - 四墓库纪律：辰戌丑未不作核心、不宜过强
  - 例外：孩子太弱可微调辰戌
- 技法
  - 未山只能「加一点点」，不能作核心
  - 三分区做局：天心位空、路径化解、边缘布局
  - 阻隔论：凶位到中心点的路径上放鱼缸
- 我的经文与老师经文
  - 我的经文：〔待补〕
  - 老师经文：〔待补〕
- 一句话：见砂是敢挣且挣着了，见水是敢想挣不着

## 坤山 · 家运（利润与幸福感）
- 身体层
  - 腹、胃肠道、子宫
  - 湿重浮肿、皮肤病、眩晕、中气虚
  - 肠神经分泌血清素 → 幸福感有生理依据
- 见水
  - 坤水伤妻房，贤妇不久长
  - 贤者损健康、不贤者损名声（底本注解，最易断反）
  - 形若破军样 → 腹胀、腹积水、肿瘤
  - 药罐伤妻房 → 常年吃药
  - 腹肿吐血面皮黄 → 脾虚湿盛
  - 对宫艮水 → 少男必孝娘
  - 坤水＋子水 → 主妇湿症、儿婚离
  - 现代三断：幸福感、肠胃、湿气
  - 缺角必应凶；补角是让能量动起来
- 见砂
  - 坤砂叠叠起，真是上元花
  - 妇女持家政，把酒喝桑麻
  - 女儿个个俊，发福庆年华
  - 若得艮水照 → 血财发无涯
  - 不许形破军、七叉与飞斜
  - 坤砂＋艮砂 → 女强男弱
  - 坤砂＋乾砂 → 主妇兴家夫怕她
  - 血财＝人头利润：团队、粉丝、流量、六畜
- 兼与叠加
  - 坤水＋艮水 → 出妈宝男
  - 坤水＋巽水 → 克妻再娶、药罐
  - 坤砂＋离砂 → 三房旺、二房难
  - 破军形 → 吉中带凶
- 技法
  - 叠叠而起：低凳 → 高几 → 高柜
  - 下山虎：坤为白虎，最后一道关卡
  - 盐灯一卦不超过两个
  - 三点定位优化：用神 → 用神先天位 → 关联诉求卦
  - 催血财：靠团队催坤艮；靠大佬催乾离

  - 老师经文：〔待补〕
- 一句话：砂是贤妻良母、家和万事兴；水是女主人不幸福、家运起不来

## 申山 · 链接（探索与艺术）
- 身体层
  - 大肠、经络、肺、骨骼、呼吸系统
  - 病多在心理，不在腹部
  - 抑郁、失眠、钻牛角尖
- 见水
  - 申水伤小女，亦主客路亡
  - 形如团圆聚 → 定主是飞娘（随人走）
  - 申方见水伤长女（底本二改「小女」为「长女」，矛盾）
  - 坤卦有水澄清蓄 → 老年妇女死道旁
  - 申庚两水 → 心肠毒辣恶相言、口舌倒垃圾
  - 诚诚恳恳经血病 → 不外放则自伤
  - 子女婚姻晚或离；孩子撒谎、骂人、PUA 家长
  - 申寅两水 → 出神卜，或抑郁、闹阴性
  - 机制：链接过强、无过滤 → 看见世间之苦 → 被苦带走
- 见砂
  - 申砂女儿美，圆面与长腰
  - 形若尖秀起，勤能通义理
  - 若与寅水照 → 丹青照优美
  - 申砂兼庚位 → 官司口舌、又哭又闹、痛经、手术车祸
  - 相由心生：脾胃好、气血好，所以脸圆腰长
- 兼与叠加
  - 申庚（兑）→ 对宫相催，兑的口舌全扔给你
  - 申寅（艮）→ 链接加倍：神卜或抑郁
  - 申水＋坤水 → 老来孤苦
- 技法
  - 催艺术：申砂为主，寅水为辅
  - 调抑郁：去水 → 立秀砂 → 艮做对应
  - 激发灵感：水杯放西南，看着水发呆
  - 坤卦健身：先练力量再练有氧
- 我的经文与老师经文
  - 我的经文：〔待补〕
  - 老师经文：〔待补〕
- 一句话：见砂看见世间的美，见水看见世间的苦

## 断卦次序
- 一看坤（中）：家还暖不暖、女主人身体
- 二看未：钱走哪条路，敢挣且挣着 or 敢想挣不着
- 三看申：跟世界怎么接，孩子有没有走偏
- 三山皆水：先看对宫艮，水则妈宝、砂则女强男弱
- 布局守纪律：四墓库不作核心，未山只加一点点
- 记住：坤管利润，不管财库
