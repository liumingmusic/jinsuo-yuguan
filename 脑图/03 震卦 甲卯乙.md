# 三碧震卦 · 甲卯乙

## 卦论断（一卦之体）
- 三碧震：长男、奋起、正官
- 事业、行动力、后天成长的机缘与天赋
- 肝、胆、筋骨、手指
- 成长上限：不给起跑线，给后劲
- 四官卦之「实权」：政令能不能传下去
- 一句话：震不是天赋，是「肯不肯一直干」

## 卦见水
- 三碧沟塘破，其家定遭祸
- 两个来源：行动力不足（一屋懒蛋）／行动力滥用（乱投乱闯）
- 长房不损丁即损财；有财则无子或败家子
- 流神通巽地 → 官飞巳次过；家庭纷争不断
- 艮水若交会 → 兄弟反目、争斗官司
- 震水入巽 → 女盗夫君男换妻
- 震艮两卦水聚 → 长房贫寒兴三房
- 大房先贫后富贵 → 艮水流入乾
- 震水遇兑艮砂 → 一四七房绝
- 应期：三碧之运、酉年尤验
- 一句话：水把「动」变成「乱」

## 卦见砂
- 三碧全体砂，文武共兴家
- 若配乾兑水 → 上中一鲜花
- 形若贪狼样 → 人秀分外嘉（起伏有致、刚健）
- 震位高大乾兑水 → 执政官权众民夸
- 再显艮水配合 → 各房齐达
- 相连艮卦山 → 官权高贵缺儿郎
- 震巽砂配乾艮水 → 官贵与富豪
- 官贵不顾离有水 → 退出官场又经商
- 一句话：震要「满」，满则成官局

## 卦应期与元运
- 上元、中元（一二三四运）最灵
- 三碧之运、酉年尤验
- 现为离九运：先调离，震作辅
- 分龄：二十岁调震、三十岁调坎、五十岁调坤

## 卦兼与邻卦
- 先天位取艮（东北）：震在先天居东北
- 震位所藏先天为离：三点定位取丙（正南）
- 对宫兑（西）：水则口舌、砂则官司手术
- 邻卦巽（东南）：长男长媳，家庭氛围
- 邻卦艮（东北）：兄弟宫，也管子孙
- 两说并存：先天位取艮或取丙，见存疑

## 技法 · 四官卦
- 乾（西北）：作风、领导支持、贵人
- 震（正东）：执行力、实权
- 艮（东北）：群众基础、下属
- 离（正南）：名气、开明、眼光
- 为官四问：上面支持？自己干得动？下面配合？名声眼光？
- 调家运：家风调乾、没劲调震、孩子调艮、规划调离
- 震与艮分工：震是自己干不干得动，艮是下面配不配合

## 一卦三山总纲
- 中间山主健康，两侧山主人事
- 卯居中 → 肝与关节；甲乙 → 有没有劲、怎么用
- 三山讲同一股「动」的三层
- 甲＝地元龙（实际含义：有没有）
- 卯＝天元龙（根本内涵：跟谁）
- 乙＝人元龙（人性影响：怎么用）

## 甲山 · 行动力（奋进之力）
- 身体层
 - 胆、肝、脑神经、面部神经
 - 面瘫、抽、阴阳脸（左右不对称）
 - 腹胀、肝腹水、胆结石、偏头痛
- 见水
 - 甲水主贫穷，长房不兴隆
 - 「贫穷」今译：佛系、躺平、平凡、小市民
 - 形若斜飞去 → 长房绝踪（娶不下、没人跟）
 - 黄肿大等胀 → 黄疸、肝腹水
 - 肝胆疾病并头痛 → 结石多应长房
 - 甲水见兑水 → 又穷又爱吹，酒后骂人
 - 甲寅兼真水 → 疯癫、半身不遂、面瘫（应家中男性）
 - 病理链：懒 → 不出汗 → 抑郁 → 肝郁 → 病
- 见砂
 - 一马不断甲龙官 → 一马当先
 - 上中时势大吉风 → 上中元最旺
 - 若得庚酉波浪起 → 后劲，运势不绝
 - 若在湖中连天涌 → 人中龙凤
 - 甲山酉水逆坤流 → 水火既济
 - 甲庚对宫两并砂 → 富贵不全缺儿郎、官场牢狱
 - 甲峰如见丙庚水 → 富贵双全
 - 震卦独有一条：对宫水必须大、必须连波
- 兼与叠加
 - 甲寅（艮）兼水 → 对宫相催，矛盾转给艮
 - 甲水＋兑水 → 对宫增益，口舌之相
 - 甲庚两砂 → 富而有患：口舌、牢狱、子孙
- 技法
 - 普通三点：甲＋艮＋兑（求事业）
 - 升级三点：甲＋兑＋丙（求名、粉丝、流量）
 - 三神过水法：小神→中神→大神，留财用
 - 布局：甲山博古架/泰山石；对宫大鱼缸动水
 - 忌：把甲山做成形煞
- 自译经文
 - 甲水主贫长房衰，斜飞绝嗣腹胀灾
 - 兑水相逢空说大，寅兼真水癫半腮
 - 一马奔腾甲龙来，庚酉波翻运自开
 - 丙水三点名俱遂，庚砂并起缺儿胎
- 一句话：见砂一马当先，见水佛系躺平

## 卯山 · 人脉（琼林与桃花）
- 身体层
 - 肝、四肢、十指、毛发、关节
 - 食指特殊：六指、脚趾异常、腱鞘炎
 - 正东见水＋正西见砂 → 阴阳颠倒，手脚有亏
- 见水
 - 卯水属同人，先富小财神
 - 家物他人有，伯道在本身
 - 形如方深聚，近对作城门 → 先吉后凶
 - 现代：钱花不到刀刃、为他人做嫁衣
 - 贷款型：花呗、房贷、车贷，给银行打工
 - 大方型：别人借钱都借得到
 - 男性：养小三、大保健，钱花给别人
 - 卯水再见酉水 → 飘浮淫秽破家婚、左手缺指
 - 两条投资禁忌：坎卦坏、卯山见水
- 见砂
 - 卯砂能致富，血财发无涯
 - 长子风四海，性好采野花
 - 形若己案拱 → 威名振三通（红顶商人）
 - 形如鸡爪样 → 军贼产其家
 - 若照单酉水 → 多生女娃娃
 - 酉水照 → 女秀文艺男理财
 - 再见艮位添秀水 → 人丁财旺懂孝礼
 - 午尖砂 → 长房突命亡（心脏）
 - 血财靠人脉：中介、平台、婚介
- 兼与叠加
 - 卯砂＋酉水 → 生女孩技术，+20% 几率
 - 卯水＋酉水 → 婚姻破、手部应灾
 - 午尖砂 → 心、血压、眼疾
 - 鸡爪形 → 出贼、出匪、职业打假
- 技法
 - 三点定位：卯砂＋艮水 → 丁财两旺
 - 卯山要秀美环抱，忌怪石尖射
 - 催人脉：卯砂为主、兑水为辅
 - 应期：卯亥午戌四字并列，非三合
 - 只按属相断：卯应兔、酉应鸡
- 自译经文
 - 卯水同人小财神，家物终归他人身
 - 酉水再叠淫破室，缺指应手痛难伸
 - 卯砂致富血财多，长子声名四海波
 - 形若案拱官贵起，鸡爪一出贼满窝
- 一句话：见砂人脉变钱，见水钱都花在别人身上

## 乙山 · 文气（如何自处）
- 身体层
 - 肝、项部、头发、手指
 - 肝郁气滞、久治不愈的肝病
 - 乙辰水成形煞 → 女性乳房手术
- 见水
 - 乙水曲曲钩，叔嫂暗相偷
 - 旧注「长男肝病不能满足妻子」→ 讲师明确否定
 - 现代：浪漫主义过重、不切实际、伪文艺
 - 形如破军样 → 肝疯病不休（肝郁化火）
 - 临卦主运乱 → 流年甲卯乙时急转直下
 - 大运三与七 → 财富不到头
 - 乙辰见明水 → 女孩婚姻阻碍、性格霸道
 - 乙水＋坤水 → 超级迷信，自修丹道
 - 机制：不是懒，是「闲」出来的虚无
- 见砂
 - 乙砂发文章，几个读书郎
 - 形似朝笏起 → 为官名显扬（力弱，不必过解）
 - 形如笋笔样 → 翰墨字亦香
 - 若遇辛水照 → 尤主内贤良（对宫相催给后劲）
 - 口吐莲花教讲台，辛秀井水有源泉
 - 乙辰马形骆驼峰 → 出富翁
 - 乙庚两砂相合 → 文昌内发世无功
 - 催文科，不催理科
 - 应验：完形、阅读、文言、文艺解读
- 兼与叠加
 - 乙水＋辰水 → 婚姻受阻、乳房手术
 - 乙水＋坤水 → 迷信、开天眼
 - 乙庚两砂 → 吉则文昌，凶则文化自负
 - 单辰砂无乙 → 搞垄断、明抢暗偷
- 技法
 - 书房最贵重书橱放乙山
 - 孩子文科差：乙山立秀砂＋酉水
 - 走艺术：乙砂＋申砂同做
 - 想靠文化做企业：乙＋庚两砂相合
 - 前提：整个震卦不能烂，单点补无用
- 自译经文
 - 乙水曲钩叔嫂偷，破军肝病几时休
 - 三七大运财难守，辰水同来女亦愁
 - 乙砂发秀出书郎，笋笔朝笏姓名香
 - 辛水一照贤内助，文昌内发世流芳
- 一句话：见砂读书教化内秀，见水浪漫过头活在幻想

## 断卦次序
- 一看甲：这个人还想不想干
- 二看卯：人脉是助力还是漏斗
- 三看乙：劲使在读书上还是幻想上
- 三山皆水：先看对宫兑，水则口舌、砂则官司手术
- 布局先看元运：上中元最灵，离九运先调离
- 分龄：二十调震、三十调坎、五十调坤
- 记住：震给不了起跑线，只给成长上限
