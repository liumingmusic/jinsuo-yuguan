# 一白坎卦 · 壬子癸

## 卦论断（一卦之体）
- 一白坎：财库、家底、精气神
- 抗压容错率、逆商
- 生殖泌尿系统、下丹田
- 桃花
- 身体层：生殖泌尿、耳道、体液、肾功能
- 生活层：家运、财库、精气神
- 能力层：抗压、逆商、工作能力、性能力、桃花
- 一句话：坎是一家的「藏」，藏得住才谈得上发

## 卦见水
- 总断：精气神差 → 财运不佳、妇科问题
- 定性三看：长期存在 / 流量大 / 连通它卦
- 坎流若巽 → 三房财不好
- 贫寒应：老二、老五、老八
- 水形七叉 → 家道中落
- 坎水入乾 → 老父旺、父亲乖
- 坎水入艮 → 兴三房、老三俊
- 坎乾艮三连 → 吉在水口、坎必凶
- 坎水入巽 → 老大老二绝嗣，老三稍好
- 坎兑离都见水 → 先贫后富、妻子贤惠
- 坎水＋兑离砂 → 二五八子无后
- 坎水＋兑震水 → 意外得财，拿命换的〔待校〕
- 为什么：坎为藏，水把「藏」变成「泄」

## 卦见砂
- 坎全砂 → 富贵，二房发
- 环抱砂最优：形优美、隔溪隔水、不逼压宫
- 砂太近 → 不分房份，皆应
- 中间断（寒透风）→ 二房丁损财耗
- 无离水相配 → 孤单贫〔待校〕
- 坎砂＋艮砂 → 老三应凶、绝嗣
- 坎砂＋艮乾砂 → 老三无子、求财难
- 一句话：坎要「实」，实才藏得住

## 卦应期
- 子年兴家、午年败家
- 时→日→月→年，能量逐级提升
- 日应只到头疼腰疼，年月才应「灾殃」

## 卦兼（四组）
- 壬亥兼水 → 血糖、糖尿病、血稠、造血弱
- 壬亥兼砂 → 严重肾病、脑疾
- 癸丑兼水 → 得肾病
- 癸丑兼砂 → 结石、左脚扭伤
- 兼的前提：跨卦 + 一喜一恶 + 相邻（三条件同时满足）
- 后果：凶性在两卦间转移，不是相加

## 一卦三山总纲
- 中间山主健康，两侧山主人事
- 坎：子居中 → 身体；壬癸 → 人事
- 三山共一个「藏」字：壬藏气、子藏神、癸藏血
- 壬癸应个人，子应全家
- 房份：坎应二房，兼看一四七 / 二五八 / 三六九

## 壬山 · 财富能力（主阳）
- 身体层
  - 肾阳、男性之力、前列腺
  - 精力不足、懒、腰疼
  - 阳虚：驼背、点头哈腰、自卑
- 见水
  - 壬水没儿郎，先绝是二房
  - 形如一箭去 → 小口命难长
  - 形如葫芦样（倒扣＝凹风煞）→ 腰肾伤
  - 四季澄清蓄 → 淋浊、疝气
  - 水少而清：能有子但穷
  - 水大势猛：能富贵但子嗣难
- 见砂
  - 壬砂高大发武贵
  - 出入佳备振海内
  - 再得丙水来对照 → 文武双全
  - 若是庚水来相遇 → 三点成局
  - 壬砂丙水见庚水 → 必出官员大富豪
- 形煞
  - 一箭去：水流直去 / 楼梯直下
  - 葫芦倒扣：四面山夹、水汇其中
  - 壬亥火尖砂：头脑血压病
  - 脏臭水：病煞并上
- 兼亥（坎 + 乾）
  - 三条件：跨卦 + 一喜一恶 + 相邻
  - 壬水兼亥：老父受气、官非、三高
  - 壬砂兼亥：中年男子痛风、血压、偏头痛
- 技法
  - 三点定位：本卦 + 对宫 + 先天位
  - 对宫相催：只放大、不矫正
  - 飘转（布局用飘、论断用挖）
- 自译经文
  - 甲·原稿：壬水汪汪阳气亏，二子身弱少作为
  - 甲′·扩写：壬方水盛阳先伤，二子中年最早殃
  - 甲′·扩写：北垣端秀起高峰，胆气声名众所依
  - 乙·直译：待补（老师未出坎卦直译版）

## 子山 · 财库（家运）
- 身体层
  - 精气神
  - 肾虚：没劲儿、高兴不起来、想躺平摆烂
  - 深挖到坤 → 女主人同病
- 人事层
  - 财库：存钱能力、家底、固定资产
  - 家运：一年比一年小
  - 逆商、抗压、事业根基
  - 夫妻生活的频率
- 定位
  - 根器：能量本源、一个家的根系
  - 中间山：断坎卦先看子
  - 财四卦（坎坤巽兑）之坎＝财库
- 见水
  - 子水一条沟，流去不回头
  - 无子身逃外，凶死一笔勾
  - 形如项囊袋，妇女把命休
  - 坎主中男，先天坤在此 → 应在女主
  - 财库穿底：存款卡在某个数
  - 家运败落（最重）
- 三要素
  - 大小：水管 / 池 / 河
  - 形态：有没有形煞（最关键）
  - 质量：臭水比形煞还凶
- 应期
  - 鼠马年月见灾殃
  - 格局看三合，形煞看对冲
  - 本宫落七星某局 → 申子辰也应
- 见砂
  - 子砂定发富，家有金钱库
  - 存钱能力，不是挣钱能力
  - 远近无水照，丑名亦不顾
  - 子午火尖砂：大房伤亡、二房盲
  - 好砂：端正高大聚气 → 人财两得
  - 坏砂：破军 → 家丑、婚变、精气神散
- 组合
  - 子水 + 午水：桃花局（又菜又爱玩）
  - 子砂 + 午路直射：心脏（离主二女、二媳）
  - 子砂 + 先天乾有煞：有财无运、富而不贵
  - 子砂 + 酉砂：饮水机——能喝，全是渣
  - 子水连壬 → 老二；兼丑 → 老五；水大 → 二五八
- 形煞
  - 凹风煞：正北凹陷，必须补宫
  - 项囊袋：中间大两头小
  - 火尖砂：三角（塔、盐灯、顶棚）
  - 破军：砂形凌乱七叉
- 技法
  - 子位宜砂（1234 喜砂）
  - 午位宜水，但对宫相催只增强不调整
  - 本宫见水再催午水 → 桃花局
  - 现代判法：冰箱判砂，开盖鱼缸判真水
- 自译经文
  - 甲·原稿：子水一沟不回头，财库穿底万事休
  - 甲′·扩写：子砂端方金钱库，能挣能守是真财
  - 乙·直译：子水一沟直去流，财库穿底不聚财

## 癸山 · 理财能力（主阴）
- 身体层
  - 肾阴、子宫、妇科、内分泌
  - 宫寒、月经不调、腰疼
  - 取象：卵子、性生活、例假
- 人事层
  - 理财能力：不是赚，是守
  - 主女性、中女
- 见水
  - 癸水夫不遇，常为夫羞辱
  - 形若不齐正，犹被骄姑逐
  - 形若一条枪，毒死夫常哭
  - 单纯阴虚：好老婆，就是生不出
  - 有形煞：阴虚阳亢，骄横、PUA
  - 癸方有水妇不育，痛经白带子宫瘤
- 对宫丁山
  - 丁水相催：只增强、不调整
  - 丁砂叠加：左脑疼痛、中风
  - 丁砂（辛砂）：家财官非医药花
- 见砂
  - 癸砂女当家，发在上元花
  - 不问男何汉，惧内定数他 → 今读作尊重
  - 形若葫芦样，矮郎要怕他
  - 女主能发家
  - 癸砂 + 丁水：丁财两旺
- 兼丑（艮）
  - 癸丑兼砂：左脚伤、抽筋、崴脚
  - 癸丑兼水：得肾病
  - 癸水见丑砂：晚得子、胃疼、糖尿病
- 形煞
  - 一条枪：直冲直扎
  - 不齐正：水形歪斜
  - 葫芦样：灶连灶、砂两叠
  - 火尖砂：三角
- 技法
  - 女性能量局：癸 + 艮 + 巳 + 丁
  - 不成局，不用三点定位
  - 六杯清水 + 墨汁 + 黑曜石（临时法）
  - 兴奋类违禁品：癸山为核心
  - 致幻剂：亥山、巳山
- 自译经文
  - 甲·原稿：癸水潺潺妇难孕，夫妻缘浅灶头凉
  - 甲′·扩写：最怕辛砂相对起，家财官非医药愁
  - 乙·直译：癸方有水妇不育，痛经白带子宫瘤

## 断卦次序
- 一 看子：还有没有神
- 二 看壬：这个男人立不立得住
- 三 看癸：女性与钱守不守得住
- 四 三山见水：先定级，再谈应事落谁头上
- 五 催之前看本宫：本宫是水，越催越坏
- 四级递进（壬）
  - 一级：单纯见水，阳气弱
  - 二级：成形煞，阳虚症状
  - 三级：腰疼腰酸、懒、直不起腰
  - 四级：形煞大 + 形不好 + 水质差 → 不育、延及母亲
