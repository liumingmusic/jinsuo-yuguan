# 坤山 · 技法

> 坤为利润，看坤山永远要连着对宫艮看。同一个坤山配不同的艮，结果可以完全相反——单山不断事。

## 叠加：艮、子、巽

| 组合 | 后果 |
|---|---|
| 坤水 + 艮水（对宫同见水） | 出妈宝男；孩子好、母亲弱 |
| 坤水 + 子水 | 痰湿重、思虑过重、肠胃不好、家运不暖、离婚 |
| 坤水 + 巽水 | 克妻再娶、药罐不离房、淫乱 |
| 坤砂 + 艮砂（对宫同见砂） | 女强男弱 |
| 坤砂 + 乾砂 | 主妇兴家，丈夫嫉妒、没事找事 |
| 坤砂 + 离砂 | 三房旺、二房难、上中房辛劳 |

## 对宫：艮山

对宫相催是增强，不是调整。坤水艮水、坤砂艮砂，走的是同一套逻辑：先把本宫验准，再看对宫把它推向哪边。详见[坤山](Ⅱ-02-02坤卦未坤申.html)。

## 飘转：优化版的出处

三点定位优化版就出在坤卦这一课：用神卦 → 用神先天位 → 诉求卦。先天好，才会把好能量优先给用神。通用五代演进见[技法总章](附-01-01技法总章.html)。

## 深挖：坤为利润

子山是财库、是整个家的根系，坤是利润。"财库—利润—人头"构成完整链条：存得住（坎）、赚得来（坤）、养得起人头（艮）。

| 靠什么赚钱 | 催哪里 |
|---|---|
| 团队、下属、粉丝 | 坤 + 艮（孕育＋子孙宫） |
| 大佬、榜一 | 乾 + 离，不催艮 |
| 养殖、六畜 | 坤为主，艮为辅 |

## 最容易用错

只看坤山不看艮。坤砂要叠叠而起，先低凳、再高几、最后高柜，做成下山虎；形态做不好，副作用大于功效。
