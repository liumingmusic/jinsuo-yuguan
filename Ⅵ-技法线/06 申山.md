# 申山 · 技法

> 申管艺术与灵感，也最容易带进阴性因素。对宫庚一催，好的变成口舌，坏的变成经血病；调抑郁要先去形煞，再立小砂。

## 对宫：庚山

| 组合 | 后果 |
|---|---|
| 申水 + 庚水（对宫相催） | 心肠毒辣、恶语伤人；不外放则经血病 |
| 申砂 + 庚位（砂压到兑） | 官司口舌、又哭又闹、痛经，重则手术车祸 |
| 申水成团圆聚 | 小女随人走、早恋 |
| 申水 + 寅水（艮同见水） | 出神卜，或抑郁、阴性因素 |
| 坤申皆水 | 老来孤苦、无人照料 |

## 飘转：催艺术

- 家里有学艺术的孩子（美术、舞蹈、音乐），催申山，艺术生涯更顺。
- 申砂 + 寅水＝丹青优美；只催申不催寅，出的是感知力，不是技艺。
- 申山见砂的人，学周易、相学、风水也比别人快。

## 深挖：调抑郁

1. 先把申山的形煞去掉：水、洞、外机流水、杂物。
2. 在西南立一个**小而秀**的砂，不必大，秀即可。
3. 艮（东北）做对应，防止继续深化。
4. 严重者走医学路径，风水只作辅助。

激发灵感另有轻做法：水杯放右前方或准西南，看着水发会儿呆。详见[申山](Ⅱ-02-02坤卦未坤申.html)。

## 最容易用错

只催申不管寅，或拿抑郁只调山不走医学。申山的负面，多半是感知力没落到技艺上。
