# 乙山 · 技法

> 乙山催文昌最实用，但前提是震卦整体不能烂。整体没劲，单点补乙无用——用神找错，越用力越偏。

## 兼／邻卦：辰山

| 组合 | 后果 |
|---|---|
| 乙辰皆见水 | 女孩婚姻受阻、性格霸道；乳房手术 |
| 乙水 + 坤水 | 超级迷信、自修丹道、追虚无 |
| 乙水曲钩成形 | 肝郁、肝病久治不愈 |
| 乙水破军样 | 家运急转直下，财富人丁两失 |
| 乙砂 + 庚砂 | 吉：文昌内发；凶：文化垄断的自负 |

## 对宫：辛（酉）

配辛水，西边可以有水，但必须是活水、清水，不能臭。乙砂 + 庚（辰）两砂相合，做企业文化与内训。

## 飘转：催文昌

| 场景 | 做法 |
|---|---|
| 有钱有名，文化程度被诟病 | 把书房／储物间最贵重、最大的书橱放乙山 |
| 孩子文科理解差 | 乙山立秀砂（笔架、文笔峰、书柜），配辛水 |
| 想让孩子走艺术 | 乙砂 + 申砂同做（乙给文气，申给感知） |
| 想靠文化做企业 | 乙 + 庚两砂相合 |

## 深挖：乙山怎么调

- 乙山见水：先补砂（书柜、笔架），再收水，不要在正东偏南留水景、鱼缸。
- 乙山见砂：砂要秀、要尖而不射；忌怪石、忌尖角对床。
- 前提：整个震卦不能烂。

## 最容易用错

震卦本身没劲还单点补乙。先看整体，再谈这一山。
