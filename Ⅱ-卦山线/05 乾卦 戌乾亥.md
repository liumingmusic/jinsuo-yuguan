# 六白乾卦 · 戌乾亥三山

> 后天乾居西北，九星六白；乾为天、为健，是能量与信息的出口，是坤这条管道上的阀门，主一个家的家风家教与文化根脉。
> 三元龙分工：**戌为地元龙（实际含义＝磁场与沟通上位）、乾为天元龙（根本内涵＝家风家教与顶梁柱）、亥为人元龙（人性影响＝思维内核与精神内耗）**。
> 一句话总纲：**戌看能不能接通上位，乾看家风正不正、顶梁柱稳不稳，亥看思维深不深、神足不足**；三者齐了，才是"未来可期"。

> 乾卦最容易混的一处：**戌是"通不通上位"，乾是"家风正不正"，亥是"神足不足"**。三山问的是三件事，不是同一件事的三种程度；合起来是从"接引"到"纲领"再到"内核"的一条递进链。

## 卦体 · 六白乾卦整体

> 乾为天、为健，六白是其九星名。断整体先立一个前提：**乾卦的全部吉凶，都落在"家风家教"上，不落在具体事项上**——它不管你做不做某件事，只管这个家往哪儿走、有没有盼头。

### 论断

乾＝一个家的**方向与纲领**：能量与信息的出口、坤这条管道上的阀门、祖宗蒙荫的接引口。前四卦（坎、坤、震、巽）解决生活里的具体问题，后四卦（乾、兑、艮、离）跃升为精神内核；乾卦是后四卦的第一卦，所以要"带着心去学"，不能用记知识点的方式去记。

- 卦体主：天、健、父、君王、一把手、领导、贵人、玉石、金、寒、冰、大赤、良马、木果
- 五行属**金**：主刚健、主决断、主收敛，也主硬性权力
- 卦形**三阳爻相连**——纯阳无阴，乾为天，乾为健，君子以自强不息
- 在奇门借"值符"作比：值符为八神之首，代表最强的神、最大的神；乾卦也代表天地，是从高维层次向你传达的热忱与砥砺
- 身体归**头、胸、大肠、肺、右足、右下腹**：头是领导部位，肺与大肠属金；疾病归头疾、筋骨风湿、肺炎、硬性外伤
- 整个乾卦坏掉：不是"哪年出什么事"，而是**一眼看得到头的日子**——没有追求感、没有惊喜、没有对生命的体验感

**乾坤的分工是这一卦的骨架**：

| 比喻 | 坤 | 乾 |
|---|---|---|
| 管道与阀门 | 通道的宽窄、能量的大小 | 能量的品质与数量、正当的引导 |
| 仓库与门锁 | 坎是仓库，攒家底与精气神 | 乾是门锁，定方向与准入 |
| 底蕴与路标 | 震是执行力的底蕴 | 乾是接引方向的路标 |
| 漏斗之口 | 所有卦的能量信息都要流经乾坤这个出口 | 看家风好不好、能不能守住财，都要看乾 |

**火烧天门的两种形**：明火烧天门＝西北是厨房、正南开门，家中男主人压力极大、脾气暴躁，却给不了家里好的回馈；暗火烧天门＝西北见五鬼火，家中男主人头脑混乱、气息不稳、疑神疑鬼——这正是戌山见砂的象。两者都归到"开关没关好"。

一句话记住：**乾主"往上走的盼头"**——家风、方向、祖宗庇佑，都是它管；缺了它，日子照过，只是少了味道。

**贵气与富气要分开**：乾卦见水"可以不富，但一定很贵"。有钱不一定贵气——富而不贵，是家风不正、品德有差；贵气来自家风家教，是别人在任何场合都要高看你一头的那份分量。所以断乾水，先断这个家的风气正不正，再谈能不能出人上人。

**与亥山见水对照**：亥水主"老父兴家寿人康、读书就有名声扬"，乾卦见水与它特别像——都是家运兴隆、人才辈出、家风清正。用阀门的比喻说：跟高维能量开一个特别好的通道阀门、装上特别好的开关，想什么时候来就什么时候来；一心期盼、朝它努力，其他事情学会放手。

**乾卦催的文昌，不是文笔**：巽卦、乙山催的是文契、文笔、对事物的理解力；乾卦催的是原生家庭对思维意识的培养。所以"读书就有名声扬"的落点是"因为家教好"——教育不只是学校的事，家庭对孩子思维与意识的影响非常强大。水形宽大、呈环抱之势、为有情之水，孩子读书就不会差。

> 经文一与经文二、三的差别只在句式与增句：经文一是带注解的短句底本，经文二是七言改写，经文三在二的基础上多出"乾水流过兑卦出"一句——这一句就是水过兑宫出武职的技术眼，也是全段最该记住的一句。

**一句判语：上梁不正下梁歪。** 支柱人物、支柱产业顶呱呱还是软趴趴，决定了这个家是好事接踵而至，还是凶灾、诉讼、白事接踵而至。乾卦见砂，家风不清正、家主出思维乱象与行为乱象，一点也不贵，甚至有桃花之象；巽卦再一不好，对宫一照，各种作风问题就扬出去了。

**形态上先分斜飞与火尖**：斜飞砂主子媳绝，火尖砂主腰疾脑瘤、车祸血光。两者都是"硬"到身体与灾祸上，不是小惊小怪。与戌砂的"磁场混乱"相比，乾砂是纲领性、路径性的坏——坏的不是某一件小事，是方向本身。

> 经文一说的是整卦皆砂的总格局，经文二、三给的是火尖砂的极端形态与应期。三者合看，乾卦见砂的全貌就是：家风歪、顶梁柱损、身体与灾祸跟上来，应期落在先后天两卦上。

### 技法

**一、砂水是能量指标，不是物件。** 判断一样东西是砂是水，不看它"是什么东西"，只看它在当下这个位置"呈现什么性质"：能量活跃度高、密度低的是水；阻碍能量流动、让通过变难的是砂。门、窗、通道是水；高柜、书柜、大型家电、水晶玉石一类摆件是砂。冰箱制冷时四周散热、扰乱周围能量，是砂；空调内机出冷风、形成气流通道，偏水；桶装饮水机以砂为主带水性，老式波轮洗衣机以水为主。

- **砂包水／水包砂**：按"一整天"的时间占比判定——大部分时间呈砂性是砂包水，大部分时间呈水性是水包砂。
- **体量门槛**：一杯水不算，十来杯才算；一米以上、比人高的绿植算砂；40 见方以上鱼缸算水，60 见方、不带盖、带过滤的空气缸是强水。
- **中药包无砂无水**：它的作用是让能量动起来，不改变能量活跃度；能量不动，补了也没用。

**二、乾坤是出口与阀门。**

绘制要点：【画布】宽 16 cm、高 8 cm 的示意图。【方位】平视一条横向管道，自左向右推进，不标方位。【构图】管道画成两条平行线，左端宽、右端收窄；中段立一枚阀门图形，阀柄朝上；右端画一个漏斗口，口外散出数条细线代表信息；管道上方另挂三块小牌。【标注】左端写「坤·管道：宽窄与大小」，阀门旁写「乾·阀门：品质与数量」，漏斗口写「乾坤·信息与能量的出口」，三块小牌依次写「坎是仓库」「震是路标」「离是名望」；管道墨青、阀门赭红、出口铜金。【看点】从左边管道看起，先认清坤只管通道宽窄，再看乾这个阀门怎么定品质与数量，最后顺漏斗口认出所有卦的信息都从这里出去。建议尺寸：宽 16 cm，高 8 cm。

**三、三点定位的三次变形。**

| 阶段 | 配置 | 要点 |
|---|---|---|
| 第一次 | 本宫＋对宫＋先天位 | 三点卡住，先把能量立起来 |
| 第二次 | 按诉求改功能 | 同一局按诉求调：既要利润财富，也要家运顺 |
| 第三次 | 先后天相连，可免对宫 | 本宫能量足时雪中送炭，把根源做好即可 |

关键不是死抠名词，而是三点形成一个稳定的三角形。空亡线、骑缝线不放砂水，三点必须同元龙——一卦纯清，绝不兼卦。

**四、对宫＝后劲＋副作用。** 对宫像给车加油：加好油，车好就更好，后劲足、名声好；加杂油，有钱但家教不好，土豪气、富不过三代，还磨损发动机。所以乾山见水而巽山见水，家风不会一直好下去，管教断断续续，方向引导出偏差；乾山见水而巽山有砂，才是好上加好。八个卦里最吃对宫能量的是震卦，最忌放水的是乾山的对宫巽。

**五、调运次序。** 乾是纲领，先看乾再看巽；补乾卦要乾坤同补，让能量动起来。西北是佛堂、神坛一类的高砂，按"移、挡、治"三步：能移最好，移到天医、延年或喜砂的位置；不能移就在中心点连线的三分之一处放水去挡；再不行就"恶水解恶砂"，多供清水、鲜花、绿植，底色以淡色为主，不供火。

一句话：**乾卦调的是方向与风气，不是某一件具体的事；先把纲领立正，再谈别的卦。**

| 字义 | 戌，灭也，万物消灭归土；季秋，农历九月，肃杀收藏 |
| 土性 | 燥土，与未同；辰、丑为湿土。燥土火气足，克金不泄火，能把钝铁顽金锻炼成器 |
| 火库 | 戌为火库，也被称为金库——里面积着东西 |
| 物性 | 虚土、窑洞、加油站、矿山、山洞、宰杀之地——都是"存着东西"的宝库 |
| 肃杀 | 监狱、牢房、看守所、刑场、法场、殡仪馆、坟墓 |
| 火旺 | 寺观、有香火之地 |
| 身体 | 腿、命门、踝足、胃、皮肤、肌肉；命门是开关、阀门，在后腰 |
| 性格 | 见水：沟通上位、压力大、刀子嘴豆腐心；见砂：磁场乱、疑神疑鬼、朝令夕改 |
| 口诀 | **一记存东西，二记压力大** |

**戌山的关键含义＝"存着东西"与"接上位"**。戌属乾卦地元龙，地元龙管的是这个卦最直接的实际含义，所以戌山就是向上接引、把资源与关系拿过来——它不问名从哪儿来，靠接通上位换这份资源。

**命门是戌山的身体开关**。坤是灵性信息的通道，乾是通道上的阀门；坎是仓库，乾是门锁；震是执行力的底蕴，乾是接引方向的路标。落到身上，命门就是精元之门。熬夜太久、精力耗散太重，整天无精打采、吃不下东西、脑子像蒙了层猪油、舌苔厚嘴唇白，就是命门火衰：第一要务是好好睡觉；吃不下东西时喝营养高的汤面，羊汤面最好，鸡汤面、排骨汤面也行；汤里放一点醋，醋有收敛之意，把能量收敛到脾胃里、促进消化，也避免上火；每次少吃一点，坚持两三天命门就打开了。

**戌字应事，逐条记我取的取舍**：

| 断诀 | 我的取舍 |
|---|---|
| 戌有路至宅、有水至宅，主有狗来宅 | 不取，民间附会 |
| 收戌气出人 M 状秃头 | 压力大易脱发取；M 状归基因，不取 |
| 戌风出人秃头，其发浊乱／不浊乱 | 不取，出油与否归体质与养护 |
| 戌位高出宫 | 取：整个乾卦能量高都出官、出做生意的人 |
| 收戌气太重主瞎眼；辰戌丑未为四大煞 | 眼瞎不取；四大煞取——四山都有强砂水能量，脾气内外都厉害 |
| 戌风主眼疾 | 改判归离卦主眼疾 |
| 戌风主蛤蟆眼相 | 取：颅内压过大，精神压力过大、思虑过重所致 |
| 戌风火灾 | 取：戌方见砂能量重，易出突发性事件 |
| 戌风主伤女人 | 改判：伤男人，不伤女人 |
| 收戌风好佛道 | 不取；正西见水、见门才出好佛道之人 |
| 独收戌气出人不结婚、跳崖跳楼、癫狂、破官、官讼牢狱、戌砂催官 | 认现象、换归因：根子都是压力太大 |

> 戌字应事的总纲只有两个字：**压力**。有些人给自己压力，有些人给别人压力。减压法也朴素——找到自己喜欢的事情，做两天压力就没了。戌是美酒，你把戌调好了，时间在你眼里不过是游戏。

## 见水

### 经文三版

**经文一**

> 单戌水　土豪家
> 暗通匪类性如麻
> 形破军　囚官衙
> 妻子假坏不救他

底本注解：戌水出土匪，又出勾结强盗、土匪之人；如果水形状散乱如军破之样，必然会受到法律制裁。妻子不与其同流，不去营救他。

**经文二**

> 单戌水为土豪家　通匪发富性如麻
> 形若破军被官囚　老婆痛恨不救他

**经文三**

> 单戌水为土豪家　通匪发富性如麻
> 形若破军被官囚　老婆痛恨不救他
> 戌水对宫辰见水　发财不正牢狱灾
> 戌辛两字并兼水　能说会道辨道理
> 戌字见上丙字水　财富智慧文笔敬

三版的关系：经文一是带注解的底本，五言四字句式最古；经文二是七言改写本，老师称它作于"气功热时期"，改处在"通匪发富"；经文三在二的基础上增补对宫辰、戌辛兼水、丙字水三句，技术点最密。三版并列，不合并。

### 逐句转译

| 句 | 象 | 现代转译 |
|---|---|---|
| 单戌水，土豪家 | 西北偏西见水 | 向上找关系；家中会认识一两个高位者，起码对你印象不坏 |
| 暗通匪类性如麻 | 匪类＝势力大的人 | 很可能是当官的；性如麻指关系盘根错节 |
| 形破军，囚官衙 | 水形散乱如军破 | 形态坏了，领导一出事首先影响到你身上 |
| 妻子假坏不救他 | 妻子不与其同流 | 夫妻本是同林鸟，大难临头各自飞 |
| 通匪发富 | 能给你关系又给你财路的上位人 | 就是那种"官匪"，能让你打上关系、又给你财路 |
| 戌水对宫辰见水 | 戌见水、对宫辰又见水 | 赚了钱就要被别人抢：给领导铺路的人，就是做炮灰的人 |
| 戌辛两字并兼水 | 戌与辛兼水 | 能说会道辨道理，舌绽莲花、上传下达 |
| 戌字见上丙字水 | 丙是戌的先天能量来源 | 先天位好，得领导赏识是因为实力够；财富智慧文笔敬 |

**核心转译：戌山见水＝向上的关系。** 一个平头小老百姓第一次见上位者会不会不自在？会不会紧张、有压迫感？别说真见，就是知道今天即将被找去问话，一晚上能不能睡着？在紧张与压力之下，你对自己家人怎么样？答案是少了很多关怀，容易发脾气、暴躁、抱怨，看他们就烦——家里容易出"刀子嘴豆腐心""窝里横"的人，尤其是男人，因为毕竟是乾卦所在。

**两个记忆点，记牢就够用**：

1. **戌水能沟通上位能量**：这个上位者不一定是领导，可能是长辈、比你有钱的朋友，也可能是你家的神灵——神灵是开关，是高维能量的表达式，你能不能把这个开关把控好，戌山给你答案。
2. **戌水者压力大，进而不会表达爱**：想对姑娘好点，见了面就开始数落；爱得很深，家人感受到的却是"这个男人不行"。压力之下表达不好，就是六亲缘浅。

**六亲缘浅与"没苦硬吃"**：明明家里饭都做好了，非端着碗去旁边蹲着吃；明明能去医院看病不去，非在家里待着；明明每顿都有新菜，非吃剩饭。对你好吗？真爱你，但方式确实错误，因为他心里有压力。修行者、信佛信道的人也常六亲缘浅——举头三尺有神明，天天与神明为伴，却学不会跟神明好好沟通，于是觉得家人是俗人。殊不知身边每一个爱你的人，都是活菩萨。

**化解方向：把单戌水引大、引到辛山。** 遇到单戌水不是去压，而是把水引到乾山、引到辛山，扩成戌辛兼水——人就从"背黑锅"变成"会说话"。能吸引上位者给的压力，更能享受上位者给的好处，心情就好了。

**单戌水 vs 戌辛兼水——同一句传话，两种结局**：

| 对比项 | 单戌水（不会说话） | 戌辛兼水（会表达） |
|---|---|---|
| 领导说明天加班两小时 | "你们听好了，明天领导要求加班 2 个小时" | "告诉大家个好消息，明天终于有机会跟领导说一下年终奖的事了，大家有什么诉求今晚想好" |
| 下属反应 | 别人不骂领导，会骂你 | "太好了"，占用一点下班时间也不算什么 |
| 结果 | 被当枪使，坏事往你身上堆、好事归领导 | 领导对我好，同事对我也好；既照顾情绪，又能把事办成 |

> 二十四山里有两处最特殊的交界：乾与兑之间的戌、辛，主对内的上传下达；震与巽之间的乙、辰，主对外的宣传吸引。戌辛兼水的人能把事情说明白、讲透彻，一般在任何事业体里都能担任好办公室主任这样的角色，创业时也能做好平台。

## 见砂

### 经文三版

**经文一**

> 戌砂号火星　定主回禄惊
> 形若兼破碎　亦怕鼓盆吟
> 形如反门背　为盗又投军
> 若遇辰水照　逆水乱胡行

底本注解：回禄是火神之名，引申指火宅，故戌砂易招惹火险、有惊恐之事；戌砂形状破碎，家中易有令人恐惧之怪异现象，如盆自吟等，对人从心理到生理都有不利；戌砂形状如同门背之丑陋不整齐，家中出盗贼，也出军贼，对宫再有辰水相对应，坏的影响会加大一倍以上，出败家之人，必破败祖业。

**经文二**

> 戌砂官司意外灾　形若破碎女产难
> 砂形反弓直射冲　长二房人凶死逢
> 如有辰水相对照　逆水定出匪子孙

**经文三**

> 戌砂官司意外灾　形若破碎妇产难
> 砂形反弓直射冲　长二房人凶死逢
> 如有辰水相对照　逆水定出匪子孙

> 戌丙砂来见辰水　手术破财或牢狱
> 戌辛兼砂官非灾　口言结巴心狠毒

三版并列：经文一给出回禄、破碎、反门背三个形态与注解；经文二改七言，加"官司意外灾"；经文三再增三句，把先后天（戌丙）、对宫（辰水）、兼卦（戌辛）三点定位全部串进来。

**核心判定：磁场混乱，不是能量低，也不是能量过大。** 坤卦见水是能量太大、接不住；戌山见砂是磁场乱了——"咱们就是乱子"，家里的磁场是乱的。家里刚有人去世，碗柜里筷子、盆动不动自己响一下，就是灵性能量遏制不住，不该来的来了、该来的不来，造成混乱局面，老师把这种象叫"灵骚"。

**现场一眼断**：到一家公司，看见西北角一个大冰箱，冰箱上放微波炉，微波炉旁边还放个烛台——不必问，直接说：管理混乱、员工不能各司其职；领导层朝令夕改；官非不少、律师函不少；动不动还出点小火灾。这是三点定位之外的"一眼断"：西北同时有砂与火，砂水杂乱、火气扰局。反过来也能"看老板断西北"：老板开明、上行下效好、会说话、对员工关怀，西北绝对好；对上有能力但对员工差点意思，一直涨工资却整天骂人，就是西北有砂包水、砂水混乱，尤其戌山。

**戌辛兼水 vs 戌辛兼砂——同一组兼卦，水砂两侧相反**：

| 对比项 | 戌辛兼水 | 戌辛兼砂 |
|---|---|---|
| 底本句 | 能说会道辨道理 | 官非灾，口言结巴心狠毒 |
| 口才 | 舌绽莲花，讲道理 | 口言结巴，老伤人，甚至口吃 |
| 上司与同事 | 上传下达，领导对我好、同事对我也好 | 祸从口出、惹官非，心狠 |
| 根子 | 沟通上位能量顺畅，压力有出口 | 沟通不了，憋得急，想跨越阶层跨不了 |

**三点定位成局**：戌山见砂其实技术点上没有别的，就是三点定位——用神（戌）＋先天之根（丙／离）＋对宫（辰）＋兼卦（戌辛）。单点看是小事，成局就是大事：身体要垮、牢狱要起。

**应验在谁身上**：单纯按体系，应在家中男人、顶梁柱、男主人；属狗、属猪、三元命为六的更硬，住这个房子的人也硬，孩子属狗属猪尤其明显。

**根本还是压力**：戌山见砂的根子是过度地想好、想向上，看不清自己的实力，妄想上位，给自己造成不正当的压力。压力能通过好的上位能量释放，又能跟家里人和睦相处，戌山水的压力百分之百就是动力；释放不了，压力就把磁场、脑子、家里一起搅乱。

## 技法与布局

**一、先解压，再谈调整。** 戌山的根子是"太想好、妄想上位"；压力不减，摆什么都只是往上叠加。找到自己的天赋与使命，不强求做不适合自己干的事，这一条比任何物件都管用。

**二、把单戌水引大、引到辛山。** 见水不作压，作引；扩成戌辛兼水，人从背黑锅变成会说话。若丙位再来水，不仅有智慧，还能通过能力赚钱——这是非常高的能力。

**三、三点定位查元龙是否统一。** 用神戌、先天之根丙（离）、对宫辰、兼卦戌辛，三处必须同元龙；空亡线、骑缝线不放砂水。一旦兼了不该兼的，家中能量与人事关系必乱。

**四、学会跟不会表达的人相处。** 如果家里西北见了砂，父母经常给压力、不会表达爱，先调能量场，再试着理解他们之前那些你不理解的行为——他们想让你更好，只是方式不对。能跟他们平等和谐地交流，告诉他们"我能理解您的所思所想，我能理解您对我的爱"，相信他们也会有正确的表达。

**五、给客户的三句实话**：先问压力有没有出口；再看西北是单水还是兼水、是砂是火；最后提醒一句——爱有没有说出口。技术之外，这一山教的就是把压力转成动力、把爱说出来。

# 乾山 · 家风与顶梁柱（天元龙）

> 方位 307.5°–322.5°｜五行 金｜房份 老父／顶梁柱｜天元龙＝根本内涵
> **一句话记住：乾山看的是"这个家的方向与纲领"——见水是家风优良、老父兴家、文昌昌盛；见砂是福报受损、家风有偏、顶梁柱受伤，对宫巽水还不给后劲。**

## 山性类象

| 项 | 内容 |
|---|---|
| 卦象 | 乾为天、为圆、为君王、为父、为玉石、为金、为寒、为冰、为大赤、为良马、为木果 |
| 人物 | 上层人物、有领导地位、起决定作用的人、君王、圣人、君子、祖父、父亲、家长、军警、执法者、一把手 |
| 人体 | 头部、胸部、大肠、肺、右足、右下腹、精液、男性生殖器 |
| 疾病 | 头疾、筋骨风湿、肺炎、硬性外伤；落枕、转筋、筋滚槽也归这里看 |
| 五行 | 金，主刚健、决断、收敛 |
| 性格 | 见水：家风正、言传身教、出人才；见砂：压力传下去、管不住人、夫妻吵架才能沟通 |
| 口诀 | **一记家风家教，二记顶梁柱** |

**乾山是"没有理由的第一公理"。** 它是我们注定深爱且无法割舍的一切，是方向性的领导与纲领——不需要理由，也不需要意义。爱一个人不需要理由，践行一件事也不需要理由。所以学乾山先要破名相：一方面是名利的名，做事不要先问名利；另一方面是名词的名，不要靠概念去理解。一个凡事都要问"有什么用、能换来什么"的人，读不懂乾山。

**什么卦都能缺，乾卦不能缺**：

| 卦 | 缺了会怎样 |
|---|---|
| 艮（子孙） | 可以没有子孙，不算大事 |
| 巽（风评） | 可以不管风评、被欺负弱一点，躺平就行 |
| 坤 | 家里三天一小打、五天一大打，只要情谊打不灭也没关系 |
| 乾 | 一上来就让你对生活没有信心、一眼看到头，绝对不能缺 |

缺乾卦的第二个效应更隐蔽：**认知产生极大偏差**——没有家风、没有家教，"挣钱就行了"，二三十岁出去搞钱，等钱赚到手，心也黑了，对世间美好的向往没有了，活着如同躯壳。

**乾字应事，逐条记我取的取舍**：

| 断诀 | 我的取舍 |
|---|---|
| 乾峰高大圆诤，文武不分，出官，一般为大官 | 取：因为这是领导 |
| 穴地现乾峰亦主出大学生 | 取其内核：早年稀罕，如今落点是"出人才" |
| 乾风破官 | 与乾砂催官同看 |
| 乾砂催官 | 取，但加一句限制：催的也不是什么好官 |
| 工厂大门口收西北乾风或门口空荡，主人员流动大、效益不好 | 取：管不住人，人就留不住 |
| 乾风出癫狂人 | 归到乾字形势上，人脑子不好 |

**一条经验**：爱落枕、筋骨常出问题的人，看乾卦。震主肝胆与筋、艮主骨，但筋错位、筋滚槽这类事却跑到乾卦上——机理在于筋不在正当地方待、不听号令；乾卦管的是一个家的方向与号令，连身体里的筋该待在哪儿也归它管。

**一条主线：乾山见水，兴的是家、正的是风、厚的是福泽。** 家风优良、家道昌盛、品行兼优，福泽深厚的家庭才有福之人进来生活、生长。经文里所有句子——老父兴家、三房发达、金榜题名——都挂在这条主线上，不是零散的几样好处。

**乾卦催文昌，催的是原生家庭对思维意识的培养**。巽卦、乙山催文笔、理解力、浪漫之意；乾卦催的是父母言传身教。水形不仅宽大，还要呈环抱之势、为有情之水——"读书必然会金榜题名，有名有利，为何如此呢？因为家教好。"

**乾水见巽水：家风很好，软肋也在**。一方面家风好、教养好、家运昌盛、家风正直；另一方面耳根子软、没有城府，别人说什么就信什么，容易被欲望牵着走、被击中软肋。前提必须先立住：得先是乾卦好、家教好、家世好，才谈得上"喜形于色异缘好"；乾卦不好而巽卦也不好的，不按这一条断。

**乾卦缺了算不算水？算，但是恶水**。能赚钱，但不贵气——"富而不贵"，会赚不会花，攒不下家底。家风有没有？有，挺正，正得发邪。所以乾卦不能去，绝对不能去；补的时候乾坤同补，让能量动起来。

**风水轮、鱼缸怎么放？** 乾卦不适宜放风水轮，兑卦或离卦放可以理解；放不了鱼缸没关系，干干净净就好。西北放冰箱也行，但要整得干干净净，旁边摆张桌子、放好看华贵的东西，让乾卦舒舒服服。乾卦要的是大气、宽敞、干净，不是水多。

**乾砂伤的是顶梁柱，不是整个家运。** 它主要体现某一个问题的单一方面：一是家中扮演顶梁柱角色的人，二是家里的主要经济收入、支柱产业。比如一家人就开个店、就做一样生意，乾卦有砂，这家的支柱就容易困难、经营不佳。见水兴的是整体性的家风与品行；见砂损的是单一方面的支柱与福报——两者影响面完全不同。

**对宫巽卦是这一山的技术眼。**

![图 5-4｜乾山对宫巽水的油箱论](fig:5-4)
绘制要点：【画布】宽 16 cm、高 8 cm 的示意图。【方位】平视两辆并排的车，中间画一道竖线隔开，不标方位。【构图】左车油箱画成满桶、油色清亮，车后拖一条长尾表示后劲；右车油箱画成杂色半桶，车尾冒一缕烟表示副作用；两车上方各挂一块牌。【标注】左车牌写「乾山见水、巽山有砂」，油箱写「好油·后劲足」，车尾写「家风长久」；右车牌写「乾山见水、巽山见水」，油箱写「杂油·后劲不足」，车尾写「好两天又不行」；清油墨青、杂油赭红、牌用铜金。【看点】先比两只油箱的颜色，再看车尾的长短与烟——同一辆好车，加什么油决定它跑多远；对应到家里就是巽卦能不能给乾卦后劲。建议尺寸：宽 16 cm，高 8 cm。

对宫像加油：加好油，后劲足、名声好；加标号低的油，跑得没那么远，还会磨损发动机。落到家里有两种影响：

| 影响 | 课上说法 | 落到家里 |
|---|---|---|
| 后劲不足 | 你的家风好，不会一直好下去 | 管教断断续续，今天想起来管一管，平时好得不得了，没有持续性 |
| 本宫受损、方向偏差 | 不只不给后劲，还损害本宫能量 | 管理家庭、风气与方向性的纲领引导出偏差、出错误 |
| 长久的副作用 | 孩子表面听话背后叛逆 | 夫妻貌合神离、同床异梦 |

**铁律：调乾卦之前，先看巽卦。** 以乾山为中心调风气，巽山可以什么都没有、可以干干净净、也可以有砂，但千万千万不能放水。你把乾卦调得越好，巽卦一坏，越会出现副作用：好两天又不行了，反复；本来不管家里、天天往外跑的人，调好了两天，巽卦一坏又回去了，而且更猛。形容由先后天决定，不由对宫决定；该吉吉该凶凶是兼卦；给后劲才是对宫——三种说法各归各，不能混。

## 技法与布局

**一、补乾卦：乾坤同补，让能量动起来。** 不能只挂一个乾卦：乾卦、坤卦一起补，再配上让能量发散的东西。能量不动，补了也没用；补齐之后再放个水，也是好事。坤卦缺，家中人尤其女主没有幸福感——乾、坤两个都不能缺。

**二、佛堂在西北：移、挡、治三步。** 佛堂属砂，落在戌山，压力又大、又不会跟家里人表达、思维又混乱，整个磁场都是乱的。第一步最彻底是移：移到天医位、延年位，或移到喜砂的位置，正北、西南不错，正东、东南也行；第二步挡：西北若是长砂，找到中心点，在中间连线的三分之一处放水；第三步治：恶水解恶砂，多供清水、鲜花、绿植，底色以淡色为主，不供火。佛家佛堂多铺黄布，道家坛可铺青布；不能移、不能挡的，就连挡带治。喜砂的四个位置是坎、坤、震、巽，移佛堂时按这个选位。

**三、神像位置三条提醒**：不要放在有人住的卧室里，起卧动静不宜，神仙待的地方要干净、磁场不能乱；先分清各房间的七星磁场，再谈摆位；客厅是对宫时，可以稍微往坤卦的申山偏一偏。

**四、补角：把范围外的卦动起来。** 能把那块区域划进自家范围就划进来——铺地毯、摆家具，把电梯门作为大门，再在里头放东西补角；划不进来，就通过让能量运动起来的办法把它"变成你的"。你说你家没有乾卦，乾卦就不存在了吗？乾卦是在的，只不过不在你家的区域范围内；那个地方的能量动不起来，你用方法让它动起来，这个卦能量就属于你了。

**五、从业与传播的边界**：术数是刀，道是用刀之法与强身之法；认知不够，先伤己再伤人。出方案要面面俱到——前面要有八卦标识、九宫格、二十四山标的户型图，后面跟上十几页，写清哪个地方怎么改、什么时间放什么。传播时一旦有偏差，影响不可估量，所以要对自己传出去的东西负责。

# 亥山 · 思维内核与精神内耗（人元龙）

> 方位 322.5°–337.5°｜五行 阴水｜房份 老父／少男｜人元龙＝落在谁身上
> **一句话记住：亥山看的是"思维深不深、神足不足"——见水是气足神足、城府深、精神内耗；见砂是气虚神弱、短浅、脱疝；两边都会小儿夜啼，但一个气足、一个气虚，正好两个极端。**

## 山性类象

| 项 | 内容 |
|---|---|
| 字义 | 亥，核、骸骨：万物收藏皆坚核，人死独留其骸；引申收藏、内敛、内耗 |
| 水象 | 阴水，五湖归聚、悬河（大河之水奔流不回）、天门 |
| 场所 | 寺院、水地（江河湖海）、沟道、猪场、楼台、仓房——凡流量大、聚水聚物之处 |
| 身体 | 头、肾囊、血液、泌尿系统；阴水主体液血液，故血压、血脂、血糖归这里看 |
| 隐藏类象 | 玄武：看不见的、暗中的、深藏的——灰色收入、提成、头蒙头晕、城府深 |
| 性格 | 见水：气足神足、思维深刻、城府深、内耗；见砂：气虚神弱、短浅、发富不久长 |
| 口诀 | **一记内核，二记内耗** |

**亥山是最"奇怪"的一山**：它不是一块石头、一个卫生间，而是一组属性——收藏、内核、阴水、悬河、天门、玄武、深藏、内耗。人百年之后皮肉都没了，头发和骨头还在；亥就是那最坚硬、最内核的一部分。由此推出两层性格：一是收藏内敛，二是内耗——把能量收到最里面，既深刻，又容易自己跟自己耗。

**玄武是亥山的隐藏面**。玄武代表看不见的事物、暗中的事物：行业机密、提成、看不见的服务、头蒙头晕、方向不明确。它既能解释"心机深、城府深、不说实话但说真话"，也能解释"看不清方向"，还能解释"思维深刻但容易内耗"。底本列的 M 字额、短颈、骨骼显露一类相貌断诀，我一律不取；只取它与玄学、歌舞场所一类"看不见的收入"的对应——这里的玄学带贬义，指让人看不清本质的江湖一套。

**亥山的思维是谁给的？是乾卦给的，是家庭教育、家风导致的。** 亥作为人元龙，给人的最直接感受就是原生家庭、父母教育给予的思维体系。成长环境宽松、家庭幸福的孩子，先天气足神足，敢想、有安全感、思考比别人多一步，城府也深一些；家庭并不优渥的孩子，思维谨小慎微，不敢做长远打算，所以"发富也不会有长远规划"——目光不远、没有宏观思维。乾讲家风家教，亥讲思维内耗，是一条线的两端。

**小儿夜啼有两种成因，一定要分开**：

| 类型 | 成因 | 表现与长大后的样子 |
|---|---|---|
| 气不足（气虚神弱） | 肠胃不好、肠绞痛、积食、受惊 | 夜里哭是难受；对应亥山见砂 |
| 气太足（气足神足） | 神满不思睡、气足不思食 | 不饿也哭、精力旺；长大后想得多、敏感；对应亥山见水 |

以前孩子夜里闹，以为肠绞痛、吃了好多益生菌不管用，其实不是病，是气足。反过来说，气不足的夜啼，调整亥山就简单：清理干净，看是不是亥山见砂；气虚则消化不好、积食、肚子疼，晚上哭是因为难受。

**精神内耗是亥山见水最该记住的一句**。亥山一旦不干净，人特别容易内耗、想得多；尤其见水——神足气足、不怎么睡觉、思维活跃、精力旺盛，没处发泄就瞎想，想想就想出病来。太爱想事情的人脾胃就不好，思伤脾；想着想着难过，肺气就不宣，忧伤肺；神气太足容易出问题，想着想着生气，血压就高了。操作要点：**容易精神内耗的人，亥山一定要干净——不用放砂、也不用放水，保持干净即可。**

**办正了是城府深，办歪了是内耗**。亥山见水的人临玄武，是城府深的人——不说实话，但说真话，而且能把你带到他的套路里面。实话和真话不一样：城府深分情况，用多了就精神内耗，因为有太多秘密不愿分享，心里压的事太多；再叠加亥水见壬水，就有血液、血压问题，肝淤、血脂高、血液粘稠，是一系列连锁反应。

> **辨误："亥山见水出傻子"是错的。** 流转很广的一种说法拿"坐亥方位的人答不上问题"当证据，却回答不了"为什么亥山见水、见砂都会小儿夜啼"。亥见水的夜啼是气足神足，亥见砂的夜啼是气虚神弱——一个太足、一个太弱，正好两个极端，怎么可能是傻子？亥山见水不出傻子，反而出城府深、思维深刻的人；判断一个人是不是真傻，看他能不能问出别人答不上来的问题就够了。

**见砂的病根是一个"气虚"**：肺气不宣（背部问题）＋器官下陷（疝气、脱肛、子宫下垂）＋思维短浅（发富不久长）。凡是肺气不宣与器官下陷问题，在体系里都跟亥山见砂脱不了关系。除了旧时痨病，还容易胀气、疝气——肠子从大腿根掉出来、脱肛、器官下垂，都跟气虚下坠有关。

**对宫巳水为什么把人带歪**：亥山见砂是气虚神弱、无主见，对宫巳水再一催，就把人推向"在错误方向上勇争第一"。用油箱论说：巳山是车，亥砂是对宫的杂油——破车加破油，后劲没了、副作用大。生活里的样子是：只看眼前、目光短浅、容易被带着走，把对家的责任放到一边，去追那些"看不见的收入"与虚名，家人反而离心。

**最重的一格**：亥人杀见巳丙水，家主换肾尿毒亡——亥山见砂，对宫巳、丙再见水，几重叠加，容易尿毒症，整个血液、体液、身体的排毒系统都完蛋。这一格与"巳丙水来壬亥砂，长房中年尿毒症"互证，同一结构在不同讲次的表述，两处照录。

**见砂孩子长大后的样子**：发育慢一些、个子小一些、不爱说话、思维敏感——什么都懂，但不爱跟人交流，心里有事但不说，认生怕生。这与见水孩子"精力旺盛、气足神足、不爱吃饭、容易肠胃问题"正好相反。孩童时期两种情况都要先看是不是亥山的问题，再谈化解。

| 先天位丁山凶砂 | 丁山有问题 | 气虚体弱、中风 |

> 亥山见水见砂都不好，是二十四山里特别招人烦的一山。但"不好"不等于"要出事"——先分清气足还是气虚，再看对宫与先天，最后才谈布局。

## 技法与布局

**一、亥山先求干净。** 内耗之人、夜啼孩子先看亥山是否脏、是否见砂见水失当；不宜盲目往上加砂加水。容易精神内耗的人，亥山保持干净即可；有亥山见砂的问题，则必须化解。亥山见水的人不要吃太多补品、补药、保健品，气已经够足了，再补就过头。

**二、用亥可辅不可核心。** 可以巳为核心、用亥去催；除非本身思维层次已经很高，才可以把亥作为核心。思维是双刃剑，深没深到地方上不一定——这层叠加要不要加，我建议不要。

**三、三个三分之一与化解／布局的分工。** 前端三分之一决定砂水性质，布局从这里下手最有效，盐灯、大鱼缸要够大、开盖、方形；中间三分之一排查隐患，是化解点，设检查站、供货，重"巧"与"力"；末端三分之一保证通道顺畅，靠近太极点，不放大泰山石、大铁门、过高绿植。化解是在回程中段降温、排查、供货，只能降凶不改性质；布局是在前端从根源改造性质——两者落点不同，别混着说。

**四、砂水与房气分开。** 房气是一辆车，砂水是车上装的货。车从太极点出发、到达边界再折返，经过厨房带上火、经过卫生间带上水；墙挡得住物理意义上的风与一部分信号，挡不住作为能量指标的砂水。人与房子的关键接触有两个信息点：房屋中心点不变，另一个是本人的象意与某一卦的对应——男主人看乾，属蛇的人还要看东南辰巽巳三山。

**五、文昌学业做局：分科调，且看对宫。** 乙、辛二山管理解与表达——乙主对事物的认知理解，辛主能否表达，能理解就能表达，这是文科；巳、亥二山管逻辑与解题——巳主拔尖、快速反应，亥主深刻理解，这是理科；寅、申二山管突破性表达——申探索世界，寅清晰表达，剑走偏锋、给灵魂震撼，这是艺术。每一科都要理解"本宫＋对宫"这对阴阳，不能只补一边。

## 本卦小结

乾卦三山，讲的是同一股"向上接引"的三段：**戌给通道、乾给纲领、亥给内核**。三山都怕方向不正：戌一乱就磁场混乱，乾一歪就上梁不正下梁歪，亥一偏就思维走邪；三山也都喜"干净"——戌要压力有出口，乾要家风正、宽敞干净，亥要先求干净、不妄加砂水。

| 山 | 见水 | 见砂 | 落在谁身上 |
|---|---|---|---|
| 戌 | 沟通上位、吃到时代红利；压力大、六亲缘浅 | 磁场混乱、精怪乱异、思维混乱；辰水对冲 | 家中男人、顶梁柱；头疾血压心胃 |
| 乾 | 家风优良、老父兴家寿而康、文昌名声扬、福泽深厚 | 福报受损、家风有偏、支柱受损；对宫巽水不给后劲 | 老父、顶梁柱、支柱产业；头胸肺与大肠 |
| 亥 | 气足神足、思维深刻、城府深、精神内耗、夜啼 | 气虚神弱、短浅、发富不久长、夜啼、脱疝 | 人的思维体系、原生家庭；血压血糖／肺气与下陷 |

**三山身体信号的三层**：戌告诉你"压力从哪来"，乾告诉你"家风正不正、顶梁柱稳不稳"，亥告诉你"思维落到哪一层、精神耗不耗"。脱发、夜啼、血压这类具体症状，戌看表现、乾看纲领、亥看内核——三层合起来，才看得到一个完整的人。

**断乾卦的次序建议**：

1. 先问一句：**这个地方该不该要乾山强**——场所用途不同，同一个卦位的吉凶判断可以完全相反
2. 一看**戌**（通不通上位）——是接通上位、吃到红利，还是磁场混乱、压力压垮
3. 二看**乾**（家风正不正）——老父兴家还是顶梁柱受损，整卦是文昌贵气还是上梁不正
4. 三看**亥**（神足不足）——气足内耗还是气虚短浅，夜啼属哪一类
5. 三山都看**对宫**：戌看辰、乾看巽、亥看巳——对宫给后劲，也会带副作用；乾卦尤其要记住"调乾先调巽"
6. 三山都看**先后天**：戌看丙（离）、乾看离、亥看丁（离）与寅——先后天相连时，应期要看两个卦
7. 布局先看**一卦纯清**：三点定位三处同元龙，空亡线、骑缝线不放砂水
8. 调理次序**乾为纲领**：先把方向与风气立正，再谈坎坤的身体与财、震巽的行动与风评

> 乾卦三课的总纲：**戌看通不通上位，乾看家风正不正，亥看神足不足**。三者齐了，才是"未来可期"。整卦最该记住的一句是——它不管你做不做某件事，只管这个家往哪儿走、有没有盼头；缺了它，日子不会立刻出事，只是**一眼看得到头**。
