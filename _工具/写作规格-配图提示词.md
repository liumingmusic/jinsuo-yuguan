# 配图提示词写作规范

本文件是全站 117 张配图（Ⅰ 线 77 张 + Ⅱ 线 40 张）的统一写法。图还没画出来，
但提示词必须写到"给一个没读过这本书的人，他照着能画出来"的程度。

## 一、为什么改

原来每张图只有三行，其中「画面」常常只有一句话，例如：

```
> 画面：天圆地方作表盘，北斗作指针，四个方位分别标出春夏秋冬。
```

这句话能让人**看懂图在讲什么**，但没法拿去**画**——缺构图、缺图上要写的字、缺画法。
「标注」和「风格」两段就是把这两块补上。

目标：每张图的提示词，是一份可以直接交给画师或生图工具的完整规格。

## 二、五行结构

每张图固定五段，顺序固定，不许调换，不许少：

```
![图 3-1｜子山方位示意](fig:3-1)
> 画面：<构图与要素，写清谁在哪、有什么、朝哪动>
> 标注：<图上要出现的文字，逐条列出，用「、」隔开>
> 风格：<画法：底色、笔法、配色、视角、禁止项>
> 读法：<先看哪、再看哪、关键落在哪>
> 记一句：<这张图最该记住的那句>
```

### 各段的职责

| 段 | 回答什么 | 字数 | 硬要求 |
|---|---|---|---|
| 画面 | 画什么、怎么摆 | 40–90 字 | 必须说清**空间关系**：谁在中间、谁在边上、箭头朝哪、线连到哪 |
| 标注 | 图上写什么字 | 15–50 字 | 逐条列出，用「、」隔开；一条不许写"等" |
| 风格 | 怎么画 | 20–45 字 | 必须含：底色、笔法、视角 |
| 读法 | 怎么看 | 30–60 字 | 教人读图，不是复述画面；要有先后 |
| 记一句 | 记住什么 | 15–40 字 | 一句能背下来的话 |

### 画面：怎么写才够

按这个顺序想，缺哪块补哪块：

1. **视角**——俯视？平视？剖面？局部特写？（例：俯视平面图）
2. **底面**——画的是一张盘面、一间房的平面、一段地形，还是一条时间轴？
3. **中心物**——画面正中最显眼的是什么？
4. **周边要素**——围绕中心有哪些东西，各在哪一侧。
5. **动势**——箭头、线、河流、走势，朝哪个方向。
6. **缺口**——如果有反例、反位、禁忌，画在哪、怎么标出来。

反例：❌「画一张方位图」　✅「正北十五度扇区占画面上半，扇区内从左到右分三格标壬、子、癸，格界画虚线并向两侧标兼山方向；右上角一条弧形箭头由外往内指子位，箭头尾注"气来"；左下角一条短横线段代表墙，墙外侧标"凶"」

### 标注：怎么写

- 把图上**真的会出现的字**一条条列出来，包括方位名、山名、数字、箭头旁的注。
- 用「、」隔开，不写"等等"。
- 图上不写字，就写「无字，仅以色块与线条区分」。

反例：❌「标上各方名称」　✅「扇区内标"壬山""子山""癸山"，外圈标"北""东""西"，箭头旁标"子水一条沟"」

### 风格：怎么写

固定包含四项，写成一句：

> 底色（宣纸／米白／浅灰）+ 笔法（手绘墨线／淡彩／线描）+ 配色（主色 + 辅色 + 点缀）+ 视角（俯视／平视／剖面）

再补一条禁止项，防止画出来像 PPT：

> 无阴影、无立体、无渐变、无卡通、无照片质感

全站配色口径（写风格时统一用这套，别自造颜色）：

| 用途 | 色 |
|---|---|
| 主结构线 | 墨黑 `#12181b` |
| 水 / 生数 / 动 | 墨青 `#2c6a7c` |
| 砂 / 死数 / 静 | 赭红 `#a3543a` |
| 关键标注 / 记一句 | 铜金 `#a67c3d` |

反例：❌「写实风格，色彩丰富」　✅「米白宣纸底，线条墨黑手绘略粗，水用墨青、砂用赭红、金色只点关键标注；俯视平面，无阴影无立体无渐变」

### 读法：怎么写

- 用"先…再…"或"先…然后…"给出阅读顺序。
- 最后落到**关键的那一处**：读者看完图要能指出问题在哪。
- 不要重复画面已写明的东西。

反例：❌「图上画了三个山」　✅「先分清三段各十五度，再看箭头从哪一侧进——从缺口进的那一侧才是要补的地方」

### 记一句：怎么写

- 一句话，能背下来，最好带数字或口诀。
- 跟这一张图**只讲一件事**。
- 用正文里的原话或紧贴正文的表述，别另造一句漂亮话。

## 四、完整样例（改前 → 改后）

这是第 1 讲「图 1-1」的真实改法，其余各图照这个密度来。

**改前：**

```
![图 1-1｜斗柄与四时](fig:1-1)
> 画面：天圆地方作表盘，北斗作指针，四个方位分别标出春夏秋冬。
> 读法：先认四时在盘上的方位，再看斗柄逐季转向——指针动一圈，就是一年。
> 记一句：斗柄指东天下皆春，指南皆夏，指西皆秋，指北皆冬。
```

**改后：**

```
![图 1-1｜斗柄与四时](fig:1-1)
> 画面：俯视一张圆形天盘，正圆居画面中央、占七成，外方内圆两层边线；盘心画北斗七星连成斗形，斗柄从盘心斜指东南；盘面四边分春夏秋冬四格，斗柄尖端所指的一格压一枚铜金箭头，箭头随四季换向；盘缘外一圈留白，只标东南西北四个方位字。
> 标注：盘面四格标"春""夏""秋""冬"，盘缘四方位标"东""南""西""北"，斗身七点旁小字标"北斗七星"。
> 风格：米白宣纸底，墨黑手绘线条略粗且有轻微飞白；春青、夏赤、秋白、冬黑四季各以一色点染箭头，铜金只点斗柄尖端；俯视平面，无阴影、无立体、无渐变、无照片质感。
> 读法：先在盘上找到东南西北四个方位字，定下东南春、夏的位置；再顺着斗柄尖端的箭头看它此刻指向哪一格——斗柄转一格是一季，转四格是一年。
> 记一句：斗柄指东天下皆春，指南皆夏，指西皆秋，指北皆冬。
```

对照看，改后多了什么：

- **视角与占比**：俯视、正圆居中占七成。
- **层次**：外方内圆两层边线，斗形、箭头、格、色各在哪一层。
- **动势**：箭头随四季换向——把「会变」这件事画出来了。
- **标注**：图上真的会出现哪些字，一条不漏。
- **风格**：底色、笔法、四季配色、视角、一条禁止项。
- **读法**：从「认方位」到「跟箭头」再到「转一圈是一年」，有了动作顺序和落点。

## 五、禁止

- **不许编造内容**。提示词里出现的每个方位、度数、卦名、字，都必须在本页正文里找得到。
- **不许写"等""若干""等等"**。
- **不许出现"示意图""概念图""配图""风格自定"**这种没信息量的词。
- **不许出现口播、转录、存疑、待校、待核**一类的半成品痕迹词（已全局清理，保持）。
- **不许写现代摄影、3D 渲染、赛博朋克**这类与本站气质无关的风格。
- 图上要写的字必须是**正文真实出现过的字**，不能自己编一句格言。

## 六、自检清单

每写完一张，逐条过：

- [ ] 五段齐全、顺序是 画面→标注→风格→读法→记一句
- [ ] 画面说清了空间关系（谁在哪、箭头朝哪）
- [ ] 标注逐条列全，没有"等"
- [ ] 风格含底色、笔法、视角，外加一条禁止项
- [ ] 读法给了先后顺序，不是复述画面
- [ ] 记一句能背下来
- [ ] 没有任何本页正文里找不到的方位/度数/卦名/引文
- [ ] 没有半成品痕迹词

## 七、构建

五行写在 md 里，紧跟图行、不留空行。`build.py` 会按固定顺序渲染成图卡：
提示词三行（墨青）在上，读法与记一句（铜金）在下，中间断一道实线。

有图了把整组五行换成 `![说明](图片/xxx.png)` 即可，其余不动。
