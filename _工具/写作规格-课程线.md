# 课程线写作规格（给写作者，含 AI）

本文件是 `内容/Ⅰ-课程线/` 下 12 页的统一规格。写完一页，就对照本文件自检一遍。

## 这一线是什么

课程线不是"课堂笔记的复述"，也不是"教科书章节"。它是：

> **一个学完的人，回头把每一讲重新讲一遍——讲给三个月后忘光了的自己听。**

所以它要满足三件事：

1. **能独立读懂**：不用翻别的页，就知道这一讲讲什么、为什么这么讲。
2. **有骨架**：理法在哪、技法在哪、案例在哪，一眼看得见。
3. **有判断**：哪里我一开始想错了、哪里老师改过、哪里我到现在还不确定。

## 逐页结构

每页严格按这个骨架，标题文字可微调，顺序不换：

```
# 第 N 讲 · <讲名>

> 一句话：这一讲解决的问题。（1–2 句，不许写"本讲主要介绍了……"）

## 这一讲在整条线里的位置
（2–5 句。前一讲留下什么缺口 → 本讲补上什么 → 留给下一讲什么）

## <主体小节 3–6 个>
（按讲义实际结构分，不要为了凑数硬拆）

## 技法清单
（编号列表，每条都可直接照做；没有技法就写"本讲无技法，只有理法"并说明为什么）

## 老师原话
（逐字引用，用 > 。4–8 段，每段后面单独一行标出处：> ——第 N 讲 · <讲名>，<当时在讲什么>）

## 本课重点
（表格两列：要点 / 说明，8–12 行。要点一句、说明一句，说明要能独立读懂；
　不要写依据列，也不要在说明里塞"依据：第 N 讲"——出处本来就整页都是）

## 勾连
（2–4 条：指向别的讲、指向卦山线锚点、或指向成书时的章节）
```

## 硬约束

### 〇、配图占位（v2 新增）

正文里凡需要图的地方，插一行占位，不引真实文件：

```
![图 3-1｜子山方位示意：正北十五度扇区，标出凹风与来龙两条箭头](fig:3-1)
```

- 编号：`<讲次>-<序号>`，如 `3-1`、`7-2`。
- `｜` 前是图题（渲染成标题），`｜` 后是画什么（一句话说清要素，别写"示意图"这种空话）。
- 每页 4–7 处，插在真需要图的地方：方位盘面、砂水对比、经文对照、案例现场、时间轴。
- `fig:` 后的 id 与编号一致，只用于页内锚点。
- 构建后渲染成虚线占位框；有图了把整行换成 `![说明](图片/xxx.png)` 即可。

### 一、术语口径（写反了就是没学会）

| 必须写 | 不能写 | 原因 |
|---|---|---|
| 火尖砂 | 尖砂、破军砂（作砂形名时） | 老师第 6 讲明确纠正；破军是九星名 |
| 真水最强，看蒸发 | 空调/冰柜比真水强 | 第 3 讲校准 |
| 冰箱判砂 | 冰箱是水 | 不敞口＋外围散热 |
| 马路算砂 | 马路是虚/水 | 看活跃度，不看虚实 |
| 金锁只有大、小太极 | 中太极 | 中太极是七星概念 |
| 三合＝同一件事的不同阶段 | 三合即同五行 | 不可跨学科搬八字合化 |

### 二、引用纪律

- 老师的原话**必须逐字**，一个字不改。有口误也保留，可在括号里注〔原文如此〕。
- 我的理解与老师原话必须分开放，不能混在一段里冒充老师说的。
- 讲义没有、只有口播的内容，标 **〔口播〕**；拿不准的标 **〔待校〕**。

### 三、禁止的写法

- 套话：综上所述、总而言之、值得注意的是、众所周知、在当今社会、随着……的发展。
- 空洞评价：非常重要、意义重大、十分精妙、博大精深。
- 机械罗列："首先……其次……最后……"当骨架用。
- 自我表扬："通过本讲的学习，我深刻认识到……"。
- 编造：笔记里没有的案例、数字、出处，一律不许补。宁可少写。

### 四、篇幅

- 主体 2800–4200 字（不含表格），页面总行数 280–380 行。
- 这一档是照着原始复习笔记的密度定的（每讲原笔记 1 万–1.9 万字，压到 1/4 左右）。
- 少于 2400 字说明没读透；多于 4500 字说明在凑。宁可写细，不要注水。

### 六、和其他线的关系

- **不重复卦山线**：某一山的经文逐句、见水见砂的细目，已经写在 Ⅱ 里，这里只给结论和锚点。
- **不重复作业线**：老师批语的完整原文在 Ⅲ 里，这里只引与理法有关的那一两句。

课程线要写的是**理法与技法的推进顺序**——为什么先讲砂水判定、再讲用神、再讲太极点、最后才逐山解经。这个顺序本身就是内容。
