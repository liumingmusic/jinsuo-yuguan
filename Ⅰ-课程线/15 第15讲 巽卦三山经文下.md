# 第 15 讲 · 巽卦三山经文（下）

> 一句话：巳山见砂是「拔得头筹」，正道拔尖；巳山见水是「另辟蹊径」，在小众赛道拔尖。辰巽巳合起来是「能不能抢、能不能强、正不正」三件事。

## 这一讲在整条线里的位置

第 13 讲讲辰山、第 14 讲讲巽山，本讲补齐巳山与四绿整体经文，收完巽卦。课前判砂水一节方法论最重。

## 一、课前：砂水是能量指标，不是物件

判砂水先问：它让能量更快通过，还是更难通过。

| 小节 | 要点 |
|---|---|
| 判断起点 | 活跃高密度低是水，阻碍流动是砂；不看物件只看性质 |
| 水 | 让能量更快通过（水导电作类比）；门窗通道皆水 |
| 砂 | 让能量通过变难：高柜、大家电、玉石摆件；放进「位置」论 |
| 家电逐判 | 冰箱、外机、滚筒为砂，内机偏水；饮水机砂包水、波轮水包砂、超市冷柜水 |
| 砂包水／水包砂 | 按一整天时间占比判砂包水／水包砂；形态一变砂水就反 |
| 体量门槛 | 一杯水、小盆多肉不算；一米绿植、40 见方鱼缸算 |
| 空间尺度 | 空间越小小物件越算数；砂水的量要跟空间匹配 |
| 九宫格 | 先定每扇形该高该低：离乾兑艮宜清，震巽宜起势 |
| 砂水即阴阳 | 砂水是能量指标非物品分类；万物皆具砂水之性即阴阳 |
| 严格表述 | 不说「这东西属砂」，要说「盐灯在卧室内是否呈现砂性」 |
| 取向不死板 | 冰箱属砂不等于超市冷柜也属砂，那恰是水 |

## 二、巳山：巽卦第三山

| 小节 | 要点 |
|---|---|
| 三山位置 | 巳是人元龙，管「正不正」：正道左道都能拔尖 |
| 巳＝起 | 万物至此毕尽而起；如走秀百花齐放分不清是谁，成就易混淆 |
| 孟夏、大驿土 | 农历四月巳火最旺；大驿道路通达，临大驿土者爱奔波 |
| 类象 | 巳为蛇、巳火、大驿土；烟火汇聚之所、小城道路、寺观楼台；主炎症 |
| 身体两端论 | 应咽喉、齿、肛门、眼目、心脏；病在通道两端：食道幽门、结肠盲肠、甲状腺 |
| 巳字应事三条 | 蛇鼠同居、蛇入宅、出长颈人——封建附会，不必记 |

## 四、巳山见砂

> 形如赤蛇绕　官清似尔曹
> 形若葫芦样　有子为方丈
> 形若尖峰起　财高名声大

| 一句评语 | 「巳山见砂，在每个位置都是耀眼的新星。」 |
| 一家都不差 | 巳砂则一家不差、女人尤其优秀；巳方放砂必是翘楚 |

## 五、四绿巽卦整体见水

> 四绿满水汪　出人为匪狂
> 吃喝与嫖赌　贪恋将家亡
> 水若流入坎　必定抢余粮
> 水如流坤地　个个伤妻房
> 流神通到乾　小女必为娼
> 最怕聚震位　儿郎往西方

注解：巽卦全是旺水，为强盗之地，出吃喝嫖赌败家之人；流入坎遭抢、坤伤妻、乾为娼、震位儿郎往西方。

| 本卦满水 | 出人为匪狂、吃喝嫖赌、贪恋将家亡 | 没有自制力，挣点钱就想享乐 |

|---|---|

## 七、三山总纲与全卦收尾

| 小节 | 要点 |
|---|---|
| 巳山收束 | 见砂＝拔得头筹、正道拔尖；见水＝另辟蹊径、小众拔尖 |
| 三层递进 | 最轻脱发；中层小众爱好、被牵着走；最重不择手段的公关 |
| 见水／见砂的一天 | 见水被剥削、回家慕强、暗处找存在感；见砂垄断资源、引导舆论、回家被奉承。差别在赛道正不正 |
| 为何为「淫卦」 | 别处找不到存在感就在暗处找；把「淫」还原成价值感缺失，解法是给正道赢的路 |
| 三山分工总表 | 辰问能不能抢：砂垄断、水被抢；巽问强不强：砂自强、水慕强；巳问正不正：砂拔得头筹、水另辟蹊径 |
| 调运次序 | 巽比坎坤更早带来结果；震给行动力，巽让人抬头自信；震巽应最先考虑 |
| 反问作结 | 人人坤卦都不好，为何别人能突破阶层，你却一蹶不振 |
| 三类客户口径 | 死气沉沉→震；墨守成规→巽；缺勇气→震＋巽。先分没力气还是没志气 |
| 结语 | 辰看能不能抢、巽看强不强、巳看正不正，三者齐了才是「人间第一流」 |

## 技法清单

1. **判砂水只看性质**：看活跃度与密度，不看物件名称；说成「在此处是否呈现砂性」。
2. **时间占比定复合类型**：砂包水、水包砂按一整天里大部分时间的性质判。
3. **巳山看赛道正不正**：见砂正道拔尖，见水另辟蹊径；脱发是最轻应验。
4. **巳丙病理链**：巳是因、丙是出口，甲亢甲状腺回头看巳丙；配壬亥砂为尿毒症。
5. **顺逆水口与一卦纯清**：「汇某出」即水口有山，逆水留财；做局不兼卦，交界不放砂水。

## 老师原话

> 判断砂水，不看它「是什么东西」，只看它在当下这个位置「呈现什么性质」。
> ——第 15 讲 · 巽卦，讲判砂水的起点时

> 须知少年凌云志，曾许人间第一流。我希望你们每个人都能不忘初心、不忘梦想，成为你心中的那个人。
> ——第 15 讲 · 巽卦，全卦结语

## 本课重点

- **砂水是能量指标**：只看此处呈现砂性还是水性；复合类型按时间占比判。
- **巳山管「正不正」**：见砂拔得头筹、正道拔尖；见水另辟蹊径。
- **巳丙相催与顺逆水口**：巳是因、丙是出口，甲亢甲状腺；「某出」即水口有山，逆水留财、顺水败。
- **一卦纯清与三山总纲**：辰问能不能抢、巽问强不强、巳问正不正；震巽优先，先分没力气还是没志气。
