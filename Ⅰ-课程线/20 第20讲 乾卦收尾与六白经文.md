# 第 20 讲 · 乾卦收尾与六白经文

> 一句话：亥山那个含混的"疝气"要拆成两件事——见水气足成疝气症、见砂气虚成气疝，调理先通络再谈补益；乾卦则收在六白见水见砂六版经文与"家风家教决定思辨力"上。

## 这一讲在整条线里的位置

第 19 讲讲完亥山三山经文，留下一个没说清的口子：亥山见水、见砂都提到疝气，到底谁气虚、谁气足？本讲先把这个口子补上，再把前三讲标注"留待后续课"的六白乾卦整体见水、见砂经文各三版补齐——戌、乾、亥三山已有正篇，本讲只讲整体，乾卦到此全部收完。余下九山（艮、离、兑）尚未开讲，这里不做断语。

## 一、开场：乾卦＝家风家教＝文化根脉

乾卦比较好懂，因为它指向的是"加分"——家风、家庭教育与整个家庭理念。它一面反映父母在后天对家庭的管理和家里的风气，一面也反映主动的阴德。老师把乾卦往上引申一层：长辈、祖辈、祖宗的蒙荫。

福德深厚的人，多半生在精神层面或物质层面比较富有的家庭。财富不只是父母留下的东西，父母给的爱与正确的引导方向，是更宝贵的那份。落到理法上，乾卦好，就是这家与高维之间的通道开关好。

老师由祖宗蒙荫讲到宗祠与家族文化。中国人重祖宗信仰、家族血缘稳固，这是文化根脉里最不容易被撼动的一层。他把这层根基拆成三条：

- 对祖宗的崇敬：寒食、中元等重要节日，有一半与祭祖有关。
- 稳固的血缘：自嫡长子继承制以来，对血亲宗族的看重一直突出。
- 以"感悟"为基础的认知方式：从可知又可感的层面描述事物，最早的甲骨文看字形就能联想事物、给出可感知的概念。

象形方块字既象形又象意，文化基础就建在这上面；由此衍生《易经》、道家文化，以及百家争鸣里儒、法、墨、道、兵的先贤智慧。老师把这些对文化的认同收回到乾卦：乾卦代表的家风家教，正是文化根脉在一个家庭里的具体呈现。万变不离其宗，根没有断，也断不了。

放大到一个群体，乾卦就是这个群体的风气、素质与理念；落到一个家，乾卦就是这个家的风气、智慧、家风家教。这一段不是闲话——后面讲思辨力、讲贵气、讲见水见砂的分野，全从"家风家教"四个字推出来。

## 二、疝气辨证：先把"疝气"忘掉

有一个从群里来的好问题：亥山见水、见砂都提到疝气，到底这个疝气是气虚还是气足？老师借这一问，把含混的民间说法拆成两件完全不同的事。

他给的第一步是先把"疝气"这个词给忘掉，先认结论：亥山见水气足，亥山见砂气虚。这两句能分辨清楚，再回头看症状。为什么必须先忘？因为见水、见砂都会讲到小儿夜啼，可一个伤身、一个不伤身，根源就在气足与气虚上。

绘制要点：【画布】宽 15 cm、高 9 cm 的示意图。【方位】不标方位，只作左右两栏对照。【构图】画面自中缝一分为二：左栏画一枚鼓起的圆包，包下压「气足」二字，包旁三条细线标气滞、血瘀、寒凝，线条自包心向外堵住；右栏画一枚下坠的圆环，环下画一道下沉箭头，箭头旁写「气虚下陷」，环周围散落下垂的小标记；中缝顶端写「亥山」二字，向下分出两条短箭头分别指向两栏。【标注】左栏写「疝气症」「富贵包、疙瘩、硬块」「不伤身」，右栏写「气疝」「阴囊肿大、小腹坠胀、子宫下垂」「是病」，中缝写「先把疝气这个词忘掉」；水用墨青、砂用赭红、关键标注用铜金。【看点】先认中缝一句把词放下，再左右分看——左边是「多而堵」、右边是「少而陷」，两栏性质一字之差就在伤不伤身。建议尺寸：宽 15 cm，高 9 cm。

**亥山见水：气足不固摄，成"疝气症"**

亥山见水的人气足神满。气足的下一步若不能固摄，就生出气滞、血瘀、寒凝三种状态，代表名词正是"疝气"。但这里的疝气不是老百姓说的"肚脐鼓起来、肠子掉出来"那种器质性疝气，而是气凝血瘀寒凝的阻滞之"症"。典型表现是局部肿块：大腿上起疙瘩、肚子上硬块下不去，以及现在说的富贵包。脂肪瘤不算——那是脂肪下的东西，不是皮肤表面。老人经络退化又气足，才凝成这个包；气虚的人反而鼓不起来。

**亥山见砂：气虚下陷，成"气疝"**

亥山见砂这里的疝气不是"症"，是病，叫气疝——气虚导致心、肺、脾、肾、肠等脏器脱垂，以"下垂"为表现：阴囊肿大、小腹坠胀、子宫下垂、胃下垂、脱肛，兼有尿淋漓不尽、胸闷、心跳慢、血压不够、容易低血糖。

| 对比项 | 见水·疝气症 | 见砂·气疝 |
|---|---|---|
| 气的状态 | 气足神满 | 气虚神弱 |
| 病机 | 气足不固摄→气滞、血瘀、寒凝 | 气虚下陷→脏器抬不起来 |
| 表现 | 富贵包、疙瘩、硬块、脸肿 | 阴囊肿大、小腹坠胀、子宫与胃下垂、脱肛 |
| 性质 | "症"，不伤身 | 病，需辨证调治 |
| 一句话 | 气太足，堵在那儿 | 气太少，托不住 |

老师反复叮嘱"不要对号入座"：气虚百分之百会导致某病症，但某病症未必都由气虚而来；淋漓不尽可能是阴虚，也可能是气虚。这里只记现象与机理，身体问题请就医辨证。

情志上还有一条线：心情不好→茶饭不思→思伤脾、忧伤肺→气虚。家中顶梁柱压力过大又传给家人，一家人在心情不好、家风不良里，哪能好好吃饭？《黄帝内经》说"恬淡虚无，真气从之，病从何来"，身与心是同频共振的一对太极。

**同是气足，落点不同**

小儿气足、经络非常通畅，靠哭喊、流泪、闹腾把过足的气排出去，所以只是夜啼、不睡、精神，不伤身体。人过花甲机能退化，经络不通，气又足，排不出去，就凝成疝气症。同一个"气足"，看经络通不通，结果完全不同。

## 三、辨证施治：先通络，再补益

面对"我怎么又气足又气虚？"这一问，老师答：那是因为你本身气虚，又兼有气滞。兼具两者只有一条路——先通络。经络通畅了才有补益的资本，否则吃多少药都没用，生活方式也得跟着改。

一人一体质，一房一方案。脾虚胃弱的人若有肾的问题，先调脾，以脾肾两助的方式；先天坤卦缺又想调坎，先在补坤的基础上再益坎；离卦、震卦状态都不好却光调坎，那两个卦的砂水都调不好，光调坎不管用。

绘制要点：【画布】宽 10 cm、高 13 cm 的示意图。【方位】侧视三级石阶自下而上，不标方位。【构图】最低一级阶面画一团打结的线，旁立一块牌；中间一级阶面线结松开一半；最高一级阶面画一枚装满的粮仓；级与级之间各画一道向上箭头；最低级右侧另画一个火苗直接烤向肚脐形圆点，火苗上压一道斜杠；画面右侧自上而下拉一条竖线，标住次序。【标注】三级牌依次写「气滞，补不进去」「先通络」「再补益，才有资本」，火苗旁写「气滞者不可直接灸神阙」，竖线写「不可见症就灸、见虚就补」；水用墨青、砂用赭红、关键标注用铜金。【看点】从最低一级往上数，先看线结有没有松开——结没开就上粮仓，等于白补；再看那道被划掉的火苗，气滞直接灸只会火上添油。建议尺寸：宽 10 cm，高 13 cm。

老师给的通用做法只留原理：泡脚男女老少、四季皆可，每天十五到二十分钟、坚持一个月；艾灸神阙补气，尤宜虚寒者，但气滞者不可直接灸，需先辨证；八部金刚功、八段锦与有氧运动先把机能恢复过来；传统膏方只作通用补益之说。这些都不是医疗建议，具体适应与禁忌以医嘱和自身辨证为准。

风水与身体是同一套逻辑：看病讲望闻问切，调风水也一样——先观察这一家、每一个卦的情况，先有清晰认知，再谈下手。

## 四、知行合一与知命改命

老师借"七星"里的一句话：知命还可以改命——知命者智也，改命者勇也。敢认识自己、敢承认这方面的缺陷，是智；真正敢去改，需要勇。

所谓知行合一，不是想法与行动合一，而是内在本我与外在行为合一，达到无极之态，去除分别之心。他现身说法：认识到自己先天脾胃弱，治疗方案都以它为核心；知道自家坤卦不好，调理前先把坤卦补齐；知道自家乾卦是缺的，调风水先把乾卦补起来。

从厨房到西北也是认知的第一步：能看到压力过大是因为西北一直燃烧的灶头，能看到家庭氛围不好是因为西北放了冰箱，就是智慧。看到了还敢改——增添养鱼的责任、改厨房装修、改变生活习惯——才是知命与改命的区别。

补角之后常常"好像什么都没做"：房子还是那个房子，面积不会多一平米，但本我的能量动起来了、鼓起来了，家比以前更温馨、更像"我的家"。取舍上核心点要抓住：太一符一类最核心，挂牌次之，山海镇与麒麟是锦上添花，自己喜欢的装饰品随个人喜好——缺得少的地方贴符挂画即可，不必都放麒麟。

到知行合一之时，人不再暴躁，不再去求那些虚的表象。老师借《水浒传》鲁智深的话收束：钱塘江上潮信来，今日方知我是我。太极立起来看是螺旋上升，看似没变，实则层层升级；升到最高点回头一看，这不还是我。

## 五、六白见水：奎照、文昌与贵气

前三讲留着没讲的六白乾卦整体经文，从这里补齐。见水三版：

经文（一）：

> 六白全是水，不嫌短与长；在天如奎照，在地为文昌；无论阴阳宅，遇之发其祥；形若不斜飞，为官声名香。

经文（二）：

> 西北乾水是汪洋，不论水势短与长；在天犹如奎星照，在地必定为文昌；无论阴地与阳宅，遇上乾水发其祥；有情乾水弯弯过，文章出仁声名香。

经文（三）：

> 西北乾水是汪洋，不论水势短与长；在天犹如奎星照，在地必定为文昌；无论阴地与阳宅，遇上乾水发其祥；有情乾水弯弯过，文章出仁声名香；乾水流过兑卦出，家出军人或警官。

老师抓的重点是一个"奎"字。见"奎"想到奎木狼星，二十八宿里白虎七宿之一，位在西北——乾卦正好在西北。奎星相照为斗星、为魁，拔得头筹、第一流之星。四象七宿的复习：青龙在东，角亢氐房心尾箕；白虎在西北，奎娄胃昴毕觜参；朱雀在南，井鬼柳星张翼轸；玄武在北，斗牛女虚危室壁。

"在天如奎照，在地为文昌"——天运护佑在地，就是文昌。这里的文昌不只是催文、利考功名，更是夺魁、出人上人。乾卦见水有官贵之气：不一定要升官，但一定有贵气，因为这家家教好、家风清正，有成为人上人的资本与潜力。

| 关键词 | 老师的讲法 |
|---|---|
| 奎 | 西北白虎七宿之一，主文章、主夺魁拔头筹 |
| 文昌 | 不只是催文，更是"万般皆下品，唯有读书高"，出一流人物 |
| 贵气 | 可以不富，但一定很贵；贵气来自家风家教 |
| 与亥水对照 | 亥水长最为良，老父兴家寿人康；两家都主家运兴隆、人才辈出 |
| 乾水流兑卦出 | 三神过水法，水口倒左、逆时针；兑主突破与尖锐，出军警武职、硬性权力 |

> 亥水长最为良，老父兴家寿人康；行宽大，仕官郎，少子回家尽到房；行衢衢，已见光，读书就有名声扬。

老师用"开关阀门"作比：跟高维能量开一个特别好的通道阀门，想什么时候来就什么时候来；一心期盼、朝它努力，就会慢慢接近，其他事学会放手。富气与贵气也不同：光有钱、没地位，别人看不起，因为家风不正、教育不好、品德有差——这就是坎卦讲的"富而不贵"。

## 六、六白见砂、乾卦总结

见砂三版：

经文（一）：

> 一白砂兼有，形要梭与查；不问阴阳宅，曲抱在其中；立向宜留意，不要逼压宫；隔溪并隔水，见之不为凶；形如中然断，名为寒透风；丁损财亦耗，定主不丰隆；若无离水照，孤苦又贫穷。

经文（二）：

> 六白全是火尖砂，腰疾脑瘤出痴呆；车祸血光事常有，老父三儿寿不长；喉痛跛脚或缺唇，无学好讼做僧人；如遇辰巽巳水照，男女必定犯桃花；长房少房子媳绝，定是六白斜飞砂。

经文（三）：

> 六白全是火尖砂，腰疾脑瘤出痴呆；车祸血光事常有，老父三儿寿不长；喉痛跛脚或缺唇，无学好讼做僧人；如遇辰巽巳水照，男女必定犯桃花；长房少房子媳绝，定是六白斜飞砂；先后乾砂离火砂，午戌亥年主灾凶。

老师主讲（二）（三），（一）以经文为主。逐句讲下来：

| 经文句 | 落点 |
|---|---|
| 六白全是火尖砂 | 火尖砂是非常凶的砂 |
| 腰疾脑瘤出痴呆 | 脑子与腰都不好，腰指生育功能，核心功能出了问题 |
| 车祸血光事常有 | 容易有无妄之灾 |
| 老父三儿寿不长 | 先后天翻卦；全家寿命都不长，生活在压抑气氛里 |
| 喉痛跛脚或缺唇 | 先天性问题，祖宗阴德无法及时庇佑；缺唇即兔唇，现多可修复 |
| 如遇辰巽巳水照 | 对宫辰巽之水一照，家风不正之外再犯桃花，坏上加坏 |
| 长房少房子媳绝，定是六白斜飞砂 | 砂形斜飞，子媳早亡、无后 |

经文（三）末句"先后乾砂离火砂，午戌亥年主灾凶"是一个技术点：先后天出现联系时，应期要考虑两个卦，不能只看一个；就像七星出问题深挖到巽卦某个磁场，也要考虑两星。属相不要作为主要考虑，论断完再拿属相去合，可以再问一嘴，但不一定对得上。

**乾卦总结**

老师把整堂课收束到"奎"字与家风家教上。家风家教主要影响思辨力——能不能正确认知事物并处理事情。乾卦出问题的人思辨力往往不强，或可思不可辨，或可变不可思；思辨力多来自原生家庭给予的思维方式。

乾卦还主长寿、智慧、家运与贵气。见水则天运庇佑、家风清正、贵不可言；家运能否庇佑滋养到你，老师顺带提醒：不少乾卦不好的家庭族谱断了、家谱好久没修，有机会除了补乾卦，也修修族谱。坤卦的运是家庭运势，乾卦的运指祖宗庇佑、蒙荫。文昌功效落在"出一流人物、风云人物"上，四个字记住：未来可期——只要乾卦好，它都能蒙荫到你，是连接高维度的通道开关。

见砂则完全相反：上梁不正下梁歪。生活环境好、大运流年好，家都能败掉；家主出思维乱象、行为乱象，一点也不贵，甚至有淫乱之象，更凶的贫贱、绝后。支柱人物、支柱产业顶呱呱还是软趴趴，决定了这个家是好事接踵而至，还是凶灾、诉讼、白事接踵而至。阴宅西北若高山环抱、格局高，能出厉害人物，但同水平相比品行、家风、思辨力、长寿会弱些，容易家运坎坷。

## 技法清单

1. 断亥山先分气：见水气足、见砂气虚；见水说"症"不说"病"，见砂才说"病"。
2. 问肿块还是下垂：富贵包、疙瘩、硬块归疝气症；阴囊肿大、小腹坠胀、子宫下垂、脱肛归气疝。
3. 看年龄与经络：小儿夜啼不伤身，花甲老人或经络不通者同是气足却成疝气症。
4. 兼具气虚气滞先通络：经络不通，补益进不去；通络之后才谈补。
5. 不可见症就灸、见虚就补：气滞者灸神阙会火上添油；身体问题一律先辨证、以医嘱为准。
6. 一人一体质、一房一方案：脾虚先调脾，坤缺先补坤再益坎，离震不好光调坎不管用。
7. 知命先于改命：先认清自家哪一卦缺、哪一处压力大，再谈补角与生活习惯。
8. 六白见水见砂各认三版：见水抓"奎"与"文昌"，见砂抓"火尖砂"与"斜飞"；先后天相连时两卦应期并列。

## 本课重点

| 要点 | 说明 |
|---|---|
| 疝气两分 | 见水气足不固摄成疝气症（肿块，不伤身）；见砂气虚下陷成气疝（脱垂，是病） |
| 先忘掉"疝气" | 先认"见水气足、见砂气虚"，再回头看症状，才不会被一个民间说法带偏 |
| 气足的落点 | 小儿经络通畅能排气，只是夜啼；老人经络退化排不出，才凝成疝气症 |
| 固摄是关键 | 气足才鼓得起包；气虚的人反而鼓不起来，所以"多而堵"与"少而陷"是两个极端 |
| 调理次序 | 兼具气虚与气滞只有先通络一条路，通络之后才有补益的资本 |
| 养生边界 | 艾灸神阙、泡脚、膏方都先辨证；气滞者直接灸肚脐越灸火越大，身体问题以医嘱为准 |
| 知命改命 | 敢认知、敢承认缺陷是智，真去改是勇；补角看似什么都没做，能量动起来才是关键 |
| 六白见水 | 在天如奎照、在地为文昌，主文书功名、出人上人、贵不可言；乾水流兑卦出主军警武职 |
| 六白见砂 | 六白全是火尖砂，主腰疾脑瘤、车祸血光、老父三儿寿不长、犯桃花、子媳绝 |
| 应期 | 先后天相连看两卦，见砂（三）落午、戌、亥年；属相只作事后参看 |
| 乾卦总结 | 家风家教决定思辨力；见水则天运庇佑、未来可期，见砂则上梁不正下梁歪 |
