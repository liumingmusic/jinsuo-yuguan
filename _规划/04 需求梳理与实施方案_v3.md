### 1.1 两张功法：净宅小法事

两版内容一致，可互校。要点：

- **用途**：家中有阴性因素干扰（噩梦、睡不好、虚症、孩子夜啼、腰疼腹痛久治不愈、回家就压抑），或租新房、退烧、急事催运。
- **准备**：手机指南针定**东北艮方**与**西南坤方**；坤位地上放**两个大碗**、艮位地上放**六个水杯**；清水 + 两瓶高度粮食酒；门窗全开；选**中午午时**。
- **操作**：① 净场——健康中年男子口含白酒，从里到外喷遍每个角落，约 20 分钟；② 布局——**清水入艮，白酒入坤**，点燃白酒至酒精烧完，白酒拿走，清水放**六天**。
- **简化**：没有壮男，直接做第二步也有效。

手写版多出三点：酒用**高粱粮食酒**；喷场时"门都要打开"；"此法的其他应用"含**面试前一天催气运**。

> 这份材料正好覆盖第 9 课作业第一题"祛除阴性因素的方法总结"，v2 里我完全没读到，是重要缺口。

### 1.2 坎卦脑图：每个山都有一句"论断"

结构（一级分支）：**坎卦论断（卦整体）／坎卦兼（壬子癸）／壬山论断／子山论断／癸山论断**。

每个山的分支标签格式完全统一：

> 壬山论断：财富能力、财商、主阳、【身体】：肾阳、男性之力、前列腺、精力不足、懒、腰疼

> 子山论断：财库、家运、【身体】：精气神

> 癸山论断：理财能力、主阴、【身体】：肾阴、女性之力、妇科、宫寒、腰疼

**这个"功能层 + 身体层"的两段式标签，就是②卦山线最该沿用的骨架**——一句话先定性，再展开见水见砂。

卦整体那支还给出六类：财库、家底、精气神、抗压容错率、生、泌系统、下丹田、桃花／身体／生活／能力。兼卦那支是"壬亥兼水、壬亥兼砂、癸丑兼水、癸丑兼砂"四条，直接对应兼山技法的四种组合。

### 1.3 坤卦脑图：三版，详版带"自译经文"

详版每山四支：**见水 / 见砂 / 对宫赋能 / 自译经文**；坤卦整体还多"坤流离、坤留兑"这类特殊格局。

老师自写的经文（节选）：

> 未山见砂有余财，暴利副业臭名扬；无规则遭反噬，遵纪守法家顺畅。
> 坤山见水贤要伤，家运不好难顺畅；坤水良水两相照，孩童晕颓母亲弱。
> 坤卦见砂家运兴，悟性高深可通灵……

**这是很重要的参照**：老师自己也在写"自译经文"，而且比原经文更口语、更贴现代应事。你现有的三首诀（壬/癸/子）偏意象，老师的偏直译——**两种风格都成立，不必统一**。对我后续给其余六山出初稿，这提供了第二种可选的写法。

还有一个细节：详版里有"**应期：子年兴家、午年败家**"这种具体到年份的断法，比笔记里的"鼠马年月"更硬。

### 1.4 三份材料的权威顺序（你说"以老师批语为主"，这里落成规则）

| 优先级 | 来源 | 用途 | 冲突时 |

## 二、笔记的三部分结构

### 2.1 总体

```
第Ⅰ部分  课程线       按第 1–11 课，完整的知识推进（理法、技法、概念、案例、答疑）
第Ⅱ部分  卦山线       坎 / 坤 / 震 三卦 → 九山，每山一页，只讲这一座山本身
第Ⅲ部分  作业线       11 课题面 → 答案（引用 Ⅰ / Ⅱ）→ 老师批语 → 未做标记
附录      经文对照 / 图片库 / 术语表 / 存疑与勘误
独立件    脑图一套（3 卦 + 9 山 + 1 总览，.xmind + 网页插件渲染）
```

### 2.2 Ⅰ 与 Ⅱ 的边界（这是最容易做重的地方）

| | 第Ⅰ部分 课程线 | 第Ⅱ部分 卦山线 |
|---|---|---|
| 回答 | **为什么、怎么推出来的** | **这座山是什么、见砂见水各应什么** |
| 内容 | 砂水本质、用神、太极点、排位、先后天、应期、分龄；技法（三点定位五代演进、兼山三条件、三分区做局、四官卦）；每课的案例与答疑 | 每山的论断（功能/身体）、见水、见砂、兼卦、形煞、应期、自译经文、速查表 |
| 经文 | 只放**引用块 + 一句提要**，全文去 Ⅱ 看 | 三版经文全文 + 逐句 + 今译 |
| 长度 | 每课 1500–2500 字 | 每山 1200–2000 字（含表） |
| 例子 | 第 4 课讲"兼山三条件"→ 用壬亥举例一句带过 | 壬山页写"壬亥兼：血糖、糖尿病、血液粘稠"四条组合 |

**硬规则**：同一个事实只在一处"讲透"，另一处只给**一句提要 + 锚点**。违反就返工。

### 2.3 Ⅱ 的每山模板（沿用老师脑图的骨架）

```
【论断】一句话定性：功能层 + 身体层      ← 老师脑图原格式
【见水】三版经文 → 逐句 → 四级递进 → 现代转译 → 应事表（房份/病/财/婚）
【见砂】三版经文 → 逐句 → 布局要点 → 应事表
【兼卦】本山与左右邻山的四种组合（水水/水砂/砂水/砂砂）
【形煞】凹风、火尖、破军、路冲；现代物件判定（空调/冰箱/鱼缸/下水）
【应期】年月日分级
【自译经文】你的定稿（坎卦三山）+ 我的初稿（其余六山）对照
【速查】8–12 条，可直接背
```

### 2.4 Ⅰ 的每课模板

```
【本课要解决的问题】一句话
【核心概念】2–4 个，每个含定义、边界、常见误用
【技法】若本课有新技法，写"第 n 代 + 与上一代的差别"
【案例】讲师原话 + 复盘
【校准】本课老师批语纠正了什么
【与本课相关的山】→ 链接到 Ⅱ
```

## 三、作业线：引用制的具体做法

你说"编排的笔记已有答案就引用，不用反复回答"。落成机制：

### 3.1 每个知识点有稳定锚点

正文每个小节带 ID，如 `kan-ren-water-3`（坎卦·壬山·见水·第3条）。作业条目只写：

> **第 4 课 第 1 题**（自编壬山见砂见水经文，要求对仗工整、结合个人理解）
> → 答案见 **Ⅱ·壬山·自译经文**（`kan-ren-verses`）。本题另有老师批语 1 条，见 Ⅲ·批语汇总。

### 3.2 三类题目分三种处理

| 类型 | 例 | 处理 |
|---|---|---|
| **正文已覆盖** | 第 8 课"申山见砂见水自编经文" | 只给锚点 + 一句"该题已并入 Ⅱ·申山"，不重写 |
| **正文未覆盖、需新写** | 第 3 课"用神→人物→太极点"这条路径 | 正文 Ⅰ 有，但作业要求"按这个路径提交笔记"，需在 Ⅲ 补一份**路径版**（浓缩成四段） |
| **未做** | 第 6–11 课全部 | 标"未做"，并给出"本题需要哪些小节"的清单 → 直接当复习任务 |

### 3.3 作业章真正要新写的东西

只有三样：**老师批语汇总**（第 1、2、5 课）、**未做题的任务拆解**、**每题与正文章节的映射表**。其余全部引用。这样作业章不会变成"第二本书"。

## 四、脑图：格式与渲染

### 4.1 唯一真源用 Markdown 大纲，导出多种格式

```
_数据/脑图/kan.shan.md          ← 人写的只有这个
        │  build-mind.mjs
        ├──> kan.shan.xmind     （zip: content.json + metadata.json + manifest.json）
        ├──> kan.shan.mm        （FreeMind，幕布/XMind/多数工具可导入）
        └──> 网页内联 SVG/HTML  （插件渲染）
```

**为什么不用 xmind 当源头**：xmind 是 zip，改一个字要解包重打包，且版本间格式有差异。Markdown 缩进大纲是十年后还能读的格式，xmind 只是"导出给软件用"。

### 4.2 xmind 生成可行性（已验证）

本机现有 `.xmind` 是 XMind Zen 格式：zip 内含 `content.json`（sheet 数组，`rootTopic.children.attached` 递归）、`metadata.json`、`manifest.json`。**用 Python 标准库 `zipfile` + `json` 即可生成**，不需要任何依赖。

### 4.3 网页渲染：两条路

| | A. 自研 SVG（推荐） | B. markmap 插件 |
|---|---|---|
| 依赖 | 零 | 需内联约 600KB JS |
| 交互 | 折叠、缩放、点击跳正文（自己写，约 250 行） | 折叠、缩放、导出 PNG/SVG 开箱即用 |
| 样式 | 完全贴合站点视觉 | 默认样式，需改主题 |
| 十年后 | 只要浏览器在就能开 | 库不更新也能跑，但代码可读性差 |

我倾向 **A**：脑图结构是固定的左右分叉树，布局算法不难；而且你的偏好一直是"单文件、零依赖、十年后还能打开"。

若你想要 markmap 那种"一拖就缩放、一键导图"的顺滑，选 B 也行——把库内联进单文件即可，同样不依赖网络。
