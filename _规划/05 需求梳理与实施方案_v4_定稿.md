## 二、最终架构：一份源，三种投影

```
内容/*.md  ──build.py──▶  站点/*.html      （网页，双击可看，可推 Pages）
    │
    └────md2mind.py────▶  .xmind / .mm / .opml  （脑图三格式）
    │
    └────日后────▶  书籍（Word → PDF）
```

**为什么这样设计**：你担心的是「脑图导不进 xmind」「网页和脑图对不上」。这两件事的根子都是"从渲染结果反推源数据"。这里反过来——**md 是源，网页和 xmind 都是它的投影**，所以永远一致。改一处、跑一条命令，两边同时更新。

## 六、脑图方案（你第 3、4 条的答案）

**渲染**：markmap——开源通用插件，VS Code 的 Markdown Preview Enhanced 用的就是它。三件套已内置 `_工具/vendor/`（d3 + markmap-view + markmap-lib，共 1MB），**完全离线**，不连 CDN。

**导出**：`md2mind.py` 读同一份 md，直接写 `.xmind`（zip 内 content.json + metadata.json + manifest.json，格式已用你现有 xmind 反推验证）。已实测：坎卦 74 节点 → xmind 74 节点，**层级逐个对齐**。同时出 `.mm`（FreeMind 纯 XML）和 `.opml`。

**13 张清单**：

| 层级 | 张数 | 内容 |
|---|---|---|
| 总览 | 1 | 九山全景 + 三卦关系 |
| 卦级 | 3 | 坎（壬子癸）、坤（未坤申）、震（甲卯乙） |
| 山级 | 9 | 每山一张：山性 / 见水 / 见砂 / 形煞 / 兼卦 / 技法 |

老师已给的坎、坤脑图**直接收库比对**，不重画；震卦三山按笔记自建，标「待老师版比对」。
