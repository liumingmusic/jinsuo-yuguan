# 壬山 · 内容卡（P0 样板 · 一山六段）

> 卦：坎（后天坎 / 先天坤）｜方位：正北偏西（壬山，337.5°–352.5°）｜五行：阳水
> 主线：**肾阳 · 男人的阳性能量**
> 一句话记住：**壬山看的是"这个男人立不立得起来"——立起来是武贵，塌下去是气虚。**
> 素材来源：L3《壬山与金锁用神》§5、L4《坎卦三山经文解读（上）》§2–§7、L5《坎卦经文（下）》§2

---

## ① 山性 · 类象

| 项 | 内容 |
|---|---|
| 字义 | 「壬」为阳水，其性**流动**而**蕴藏**。三山（壬子癸）共有"藏"意，壬山主藏**精神与资本** |
| 五行 | 阳水。坎卦统生殖泌尿系统，三山分主：**壬＝肾阳（气）／子＝神／癸＝肾阴（血）** |
| 人体 | 肾、膀胱、泌尿生殖系统、淋巴；延伸主腹泻、痢疾（坎坤先后天，见 ④） |
| 性格 | 阳旺则 man、有安全感、让人信服；阳虚则自卑、驼背、点头哈腰 |
| 房份 | 主**中男（老二）**；应期次序：老二 → 老五 → 老八 |
| 行业 | 讲师举过收藏、造船、水利、航海等，均自注"扯淡"——**不作论断依据**，仅记"流动性强的行业" |
| 民间论断 | 壬亥之间高峰主出富、善储；单独过高主"书贼"（讲师明确：不能这么论，了解即可） |

**关键分主**：壬山是**阳气**这一层，不是精、不是神。所以壬山出问题，先看到的是"没劲儿"，不是"没精神"（子山）或"没血"（癸山）。

## ② 见水

### 经文三版（据讲义底本逐页转录，非口播）

**见水（一）· 民国李湘生本**
> 壬水没儿郎，先绝是二房。形如一箭去，小口命难长。
> 形如葫芦样，亦主腰肾伤。四季澄清蓄，尤主淋卵囊。

**见水（二）· 八九十年代本**
> 壬水势大没儿郎，先绝二房死水塘。水微贫穷可得子，富贵名扬没儿郎。
> 形如箭样飞流去，二房小口命不长。形若葫芦大小样，腰肾血疾应二房。
> 壬水四季澄清蓄，贫困劳苦最寒酸。

**见水（三）· 含对宫与兼卦句**
> 壬水势大损儿郎，二房夭折死水塘。水微贫穷可得子，富贵名扬缺儿郎。
> 水流悲乐哭啼声，二房小口命不长。壬水不整肾血液，贫困劳苦最寒酸。
> **壬水再得丙水照，男弱女强在文章。最怕壬水兼亥子，老父官非糖尿病。**

> 注意：第三段末两句是「对宫相催」与「兼卦」的经文出处，容易漏；二、三两段是不同流传本，句子相近但用字有别（"没儿郎"／"缺儿郎"、"形如"／"形若"），**不可混抄成一段**。

### 逐句（以民国本为纲）

| 句 | 象 | 现代转译 |
|---|---|---|
| 壬水没儿郎 | 正北见水，生女多、男丁少 | 不止"没儿子"，是**难养**：孩子从小阳气不足、定期发烧、驼背、不爱吃饭不动 |
| 先绝是二房 | 二房最重 | 祖宅看老二；阳宅看中年男子。老二 → 老五 → 老八依次 |
| 形如一箭去 | 水直冲而去／地势下坡带楼梯 | 能量被"带走并冷静住"，三山气机全泄 → 大人小孩一起阳虚 |
| 小口命难长 | 子嗣夭折 | 民国语境极重（当年孩子本就难养）；今以"难养、体弱"为主，**不宜照搬"夭折"断人** |
| 形如葫芦样 | 倒扣的葫芦＝**凹风煞**，山间水汇 | 见 ④ 形煞段 |
| 亦主腰肾伤 | 腰＝中丹田＝脾胃 | 坎见水延到坤（先后天），脘腹胀痛、五更泻 |
| 四季澄清蓄 | 常年一汪静水 | 静水不清则泌尿系统反复（淋证、疝气、尿路感染） |
| 尤主淋卵囊 | 淋巴、睾丸、子宫 | 男子器质性病变居多 |

### 四级递进（判断强度的尺子）

| 级 | 象 | 应事 |
|---|---|---|
| 1 | 单纯见水 | 阳气弱，首应老二 |
| 2 | 形成形煞 | 出现阳虚症状（畏寒、盗汗、尿不尽） |
| 3 | 形煞较重 | 腰疼腰酸、懒、不爱动、直不起腰 |
| 4 | 形煞大 + 形不好 + 水质差 | 男子不育；延及母亲——脾胃、妇科；水脏则重病 |

> 这一格是整座山的**操作核心**：**断事之前先定级**。看不到形煞只谈"没儿郎"，是照本宣科；到了第 4 级还只谈"气虚"，是不敢断。

### 贫富二选一（相对概念，必须辩证）

水少而清 → **能有子，但穷**；水大而势猛 → **能富贵，但子嗣艰难**。
讲师原话的意思是"要肾气还是要钱"。所以见到壬水**不能一口气断"又穷又没孩子"**——那是把两个极端叠在一起。

### 病象与人群

- 男子：前列腺几乎必有问题；青年即腰疼、肾虚、精力低于同龄人
- 女子：经期崩漏、漏尿、体味重（案例：四十余岁女性长期血崩止不住）
- 水质差（臭水、污染）→ 泌尿生殖系统重症风险显著升高
- 执业边界：涉生死的个案，讲师本人多数不接——**这条要写进书里的"风险自保"章**

### 案例（凯旋家）

祖宅正北极差，阴宅正北有高铁线（远）。结果：老二（其父）一支只余凯旋一人，老五、老八的孩子一走一夭。近处恰有一点砂，故老二这一支留住了人。
> 用法：这个案例同时演示了"排位 + 由远及近的能量对比"，是**一张图讲完两条理法**的典型，书里应配平面示意。

## ③ 见砂

### 经文（据讲义底本）

**见砂（一）（二）**
> 壬砂高大发武贵，出入佳备振海内。再得丙水来对照，儿孙代代以文会。

**见砂（三）**
> 壬砂高大发武贵，出入佳备振海内。再得丙水来对照，儿孙代代以文会。
> 若是庚水来相遇，风华正茂定老二。壬砂丙水见庚水，必出官员大富豪。
> 壬亥两字火尖砂，头脑血压疾病疯。

> 课堂口播把它念作「壬砂发武贵，秀峰高大位，出入加备有，大名振海内」，与底本用字不同（"高大发武贵"／"佳备振海内"）。**成品一律以底本为准，口播差异另记**——这是整理笔记时最容易丢的一条。

### 逐句

| 句 | 象 | 转译 |
|---|---|---|
| 壬砂高大发武贵 | 正北有秀丽高峰、家中做高大贵重之砂 | 出**武贵**：位高权重、有决断、有担当 |
| 出入佳备振海内 | 「佳备」＝排场齐备 | 有名声、有朋友、有排场，贵人愿意簇拥；声望在外 |
| 再得丙水来对照 | 对宫（正南丙）见水 | **对宫相催**：丙主文，文武双全。注意底本作「对照」不作「照」 |
| 儿孙代代以文会 | 文武合、代代相传 | 孩子身体好、气质佳、学历高 |
| 若是庚水来相遇 | 再补先天位（庚） | **三点定位**的经文出处 |
| 壬砂丙水见庚水 | 三点齐备 | 「必出官员大富豪」——三点定位的应验句 |
| 壬亥两字火尖砂 | 壬与亥同时见火尖砂 | 头脑、血压类病；与兼卦转移是**两回事**，要分开看 |

### 为什么是武贵不是文贵

壬主阳气、行动力、外在气势——它是"体格与胆气"这一路；文气在离（丙）。壬山单独发，只能发武；要文，必须借对宫的水。**壬山自己不带文，这是坎的性质决定的。**

## ④ 形煞与叠加

| 形煞 | 判法 | 后果 |
|---|---|---|
| 一箭去（两形态） | ① 水流直去 ② 房高屋下坡、楼梯直下 | 孩子百分百没精神；男人同理 |
| 葫芦样（凹风煞） | 倒扣葫芦：四面山夹、水汇其中 | 腰肾伤 + 延及脾胃（先后天翻卦） |
| 兼亥（壬兼乾） | 壬与亥两山跨卦相邻、砂水压在分界 | **转移内部矛盾**：血压血脂血糖必有一伤、官非、受委屈 |
| 壬亥火尖砂 | 两山同见尖形破面之砂 | 头脑、血压类病（经文「壬亥两字火尖砂，头脑血压疾病疯」） |
| 脏臭水 | 水质 | 病与煞并上，最重一档 |

### 兼山三条件（必须同时满足）

1. 不同卦的两个山（壬＝坎、亥＝乾）
2. 一喜一恶（坎喜砂、乾喜水 → 见水时乾"接垃圾"）
3. 两山相邻

砂水两种走向正好相反：

- **壬见水 + 亥见水** → 坎把"烦"倒给乾 → 老父受气、官非、三高
- **壬见砂 + 亥见砂** → 坎把"喜欢"收下？不——是乾把"烦"倒给坎 → 中年男子出问题：痛风、血压、偏头痛

## ⑤ 技法与布局

### 三点定位法（第一代，本山为出处）

| 步 | 动作 | 本例 |
|---|---|---|
| 1 | 定用神卦＝本卦 | 壬山（坎） |
| 2 | 催对宫 | 丙山（离）见水 |
| 3 | 取本卦先天位（根儿） | 庚山（正西一侧） |
| 结果 | 老家给根、对宫给势 | 壬砂 + 丙水 + 庚水 = 文武双全、名利双收 |

- 布局名：**飘转**（布局用飘、论断用挖）
- 边界：对宫相催**只增强、不调整**。壬山本身见水，丙水一催是"坏上加坏"——这是最容易用错的一步

### 兼山处理

见 ④。落地时不是"消灾"，而是**判断矛盾落在谁头上**：落在老父（乾）还是落在中男（坎），决定了你该劝谁、该补哪一方。

## ⑥ 作业三件套

### 作业原题（L4 §7.2）

1. 自己总结壬山见山见水的经文——不要抄，用自己的话写出来，对仗工整（顺口溜也行，不要求押韵）。
2. 把今天的技法写出来：兼山、三点定位。
3. 写出对壬山见山见水的个人理解——为什么见砂发武贵、不发文贵？为什么见水就没气质、虚弱、易不育？

### 我的自编经文（8 句：水四句、砂四句）

> **壬方水盛阳先伤，二子中年最早殃。**
> **水如脱矢儿难养，瓢形倒扣腰难当。**
> **一泓常静淋浊起，财旺翻教嗣息凉。**
> **更逢亥上砂水接，血压官非暗里藏。**
>
> **北垣端秀起高峰，胆气声名众所依。**
> **丙水对宫来一照，儿孙文武两相宜。**
> **庚方更得清波应，三点成局贵可期。**
> **莫向此山轻放水，一泓清浅便成疾。**

自注（写作时的取舍）：

- 「瓢形倒扣」代替"葫芦样"，取凹风煞的**形**而不借原词；
- 「水如脱矢」代"形如一箭去"，意象换成"离弦之箭"而非沿用水流如箭的说法；
- 「一泓常静」代"四季澄清蓄"，避开原句的"四季""澄清"；
- 「淋浊」统摄淋证、尿路、疝气，避"卵囊"的粗俗与过时；
- 「嗣息凉」承"人丁稀"之意，不用"命难长"——民国本的生死断言在今天不宜照搬；
- 「北垣端秀起高峰」代"壬砂高大发武贵"，把"高大发武贵"的判断句换成写景句，武气落在"胆气"二字上；
- 「亥上砂水接」把兼山写成**动作**（接），不用"兼"字，避免术语堆叠；
- 末句收总纲：**此山宜砂不宜水**，一句话记住整座山。

### 技法记录（本山亲手写一遍）

- 兼山三条件 = 跨卦 + 一喜一恶 + 相邻 ⇒ 矛盾转移
- 三点定位 = 本卦 + 对宫 + 先天位；布局用、论断不用
- 对宫相催 = 只放大、不矫正

### 个人理解（作业第三题，约 160 字）

壬山是坎卦的"阳气"那一层，管的是**一个人立不立得住**。它的能量性质是向外、向上、能扛事——所以见砂（高、实、稳）正好接住这股气，人就有体格、有胆气、有排场，出的是武贵。文气不在坎，在离，所以壬山自己发不出文贵，必须借对宫丙水来照，才是文武双全。

见水则相反：水把气泄掉、把温度降下来，人的"根火"就弱了。气虚则没气质，阳虚则腰膝无力，第 4 级连生殖功能都撑不住。所以不是"风水不好所以倒霉"，而是**同一个物理过程**——能量被抽走，人自然塌下去。

## ⑦ 差异与存疑（继承原笔记的严谨性）

| 项 | 说明 |
|---|---|
| 「葫芦样」 | 讲师明确：不是葫芦形状，是**倒扣**的葫芦＝凹风煞；不可按字面理解 |
| 「小口命难长」 | 民国语境；今以体弱难养为主，**不作生死断语** |
| 「庚水」/口播「更水」 | 同音误识，取"庚水"（前一轮校订已全篇回改为庚水） |
| **兼亥山 / 兼亥子** | 笔记正文作「最怕壬水兼亥山」，讲义底本作「最怕壬水兼亥子」。义理上"亥、子"是坎卦两个相邻之山，**底本更自洽**；但笔记已按"兼亥山"讲述并配了案例，故两者并列保存，**待听原音再定** |
| 见砂经文的底本 vs 口播 | 底本「壬砂高大发武贵，出入佳备振海内」，口播「壬砂发武贵，秀峰高大位……大名振海内」。两个都留，正文用底本 |
| 壬山先天位 | 口播称"原来在正西"，讲师自注待核；先天八卦坎居西，与三点定位的庚位可互证，但书里应标"待核" |
| 「书贼」说 | 讲师自评"不能这么论"，仅存目 |
| 行业举例 | 讲师自评"扯淡"，不入论断 |
